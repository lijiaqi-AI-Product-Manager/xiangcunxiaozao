## 〇、三分钟速读

### 0.1 如果真的赶时间，只做这五件事

1. 两台机器**都先按「关机 → 按住 FEED → 开机」打一张自检页**，把 IP 和模式记下来（第 5 章）。
2. 把两台机器接进**店里同一个路由器**，IP 固定下来（第 3、4 章）。
3. 在收银电脑上打开验证命令，两台机器的 9100 端口都要通（第 3.5 节）。
4. 填 `.env` 里的打印段，**重启后端**（第 6.3、6.6 节）。
5. 老板端 →「打印设置」→ 两台各点一次「打测试页」，出纸了才算装完（第 8 章）。

### 0.2 三个绕不过去的前提

| # | 前提 | 违反了会怎样 |
|---|---|---|
| 1 | **后端必须跑在店里，和打印机同一个局域网** | 后端上云（Zeabur、阿里云）——网页一切正常，**永远不出纸**，改配置也救不了 |
| 2 | **XP-236B 必须切到「票据模式（ESC/POS）」** | 停在标签模式（TSPL）时，状态显示通、打测试页一声不响，什么也不出 |
| 3 | **改完 `.env` 必须重启后端进程** | 环境变量只在启动时读一次，不重启等于没改，页面一直显示「未启用」 |

### 0.3 一页速查（出问题时先做这一件事）

| 你看到的 | 先做这件（30 秒） | 再往下看 |
|---|---|---|
| 两台都不出纸 | 机器电源灯亮不亮；纸装了吗；盖子压紧了吗 | 10.2 表第 1–4 行 |
| 一台好一台坏 | 坏的那台单独点「打测试页」，看页面回哪句话 | 10.2 表第 5–9 行 |
| 页面显示「未启用」 | `.env` 里 `PRINT_*_ON` 是不是 1；改完重启了吗 | 6.3 / 10.2 第 10 行 |
| 显示通，但纸不出来 | XP-236B 打自检页，看是 ESC/POS 还是 TSPL | 第 5 章 |
| 纸出来了，全是乱码 | 把那台机器的 `*_ENCODING` 改成 `gbk` 再试 | 10.3.2 |
| 右边被切掉半截 | 58mm 的机器是不是填成了 `80` | 10.3.3 |
| 早上一来就不出纸 | 打印机 IP 是不是变了（没做静态绑定） | 3.4 |
| 出过一次、这一单没出 | 老板端「打印设置」看「最近的打印记录」 | 第 11 章 |

## 一、系统是怎么出纸的

### 1.1 一条链路，两个终点

```
顾客手机扫码 ──▶ 顾客端网页 ──POST /api/orders──▶ 后端（店里那台电脑，端口 8787）
                                                      │
                                                      ├─① 先落库：订单写进 data/app.db
                                                      │     （这一步成功 = 顾客拿到取餐号）
                                                      │
                                                      └─② 异步分发（order.created 事件）
                                                            ├─▶ 小票机 Zy307：整单明细、取餐号、条码
                                                            └─▶ 标签机 XP-236B：这单里的饮品，一杯一张
```

记住两点，后面排查都用得上：

- **打印是「事后异步」的**：订单先入库、后出纸。所以「顾客看到取餐号了但没纸」是正常的现象，不代表下单失败。
- **前端不直连打印机**：手机、老板端页面都只跟后端说话。打印机连的是**跑后端的那台电脑**，不是手机。

### 1.2 什么情况出几张纸

| 场景 | 小票机 | 标签机 | 说明 |
|---|---|---|---|
| 正常下单 | 1 张 | 每个饮品 1 张 | 只点炒菜 = 只出小票，0 张杯贴 |
| 加菜（同桌上第二次点） | 1 张，单号带 `A1` / `A2` | 新加的饮品各 1 张 | 后缀是为了让后厨一眼分清「这是补的单」 |
| 取消订单 | 不出 | 不出 | 系统只在「订单创建」时打纸；要留底请手动补打 |
| 退款 | 不出 | 不出 | 同上 |
| 老板点「打测试页」 | 1 张示例单 | 1 张示例杯贴 | 不占订单号、不进营业数据 |
| 老板点「补打小票」/「补打杯贴」 | 1 张 | 该单饮品各 1 张 | 记一条新的打印记录 |

### 1.3 两台机器的分工（不要接反）

| | ZYWELL Zy307 | Xprinter XP-236B |
|---|---|---|
| 在系统里的角色 | **小票机**（前台 / 收银） | **标签机**（吧台 / 杯贴） |
| 打什么 | 整单明细、取餐号、条码、门店信息 | 每个饮品一杯一张 |
| 纸宽 | 80mm，48 字/行 | 58mm 纸（48mm 打印区），32 字/行 |
| 切刀 | **有** | **没有** |
| 接口 | USB + 网口 | USB + 蓝牙 |
| 指令集 | ESC/POS | 双模：票据 = ESC/POS，标签 = TSPL |

接反了也能用（把 `.env` 里两台的 `PAPER` / `CUTTER` 对调即可），但不建议：58mm 打整单太挤，80mm 打杯贴费纸。

### 1.4 打不出来，为什么订单还能正常下

这是故意设计的，不是漏洞：

- 打印在一个**串行队列**里跑，每台机器一条队列，互不阻塞；队列卡住只影响出纸。
- 每张纸失败会**自动重试 2 次**（间隔从 1500ms 起翻倍），仍然失败就记一条失败记录，然后放弃。
- 每次尝试（成功 / 失败 / 打了几张）都写进 `print_jobs` 表，老板端「打印设置」能看到，不会静默丢单。
- 后端重启**不会重打**历史订单：打印只在订单创建那一刻触发，补打必须手动点。

> 一句话：**纸可以不出，生意不能停。**

- [ ] 打印机主机 ×2

> 选打印服务器只有一条硬指标：**必须支持 RAW 9100（JetDirect）**。只支持 LPR 515 的便宜货，这套代码用不了。买之前问一句客服「支不支持 RAW 9100 端口打印」。
> 另外别买成「USB 共享切换器」——那是插鼠标键盘的，不是网络打印服务器。

### 2.4 耗材估算与备货

- 一张小票约 **22 cm**；一卷 80×80mm 约 60 米 → **约 270 张**。按一天 100 单算，**3 天左右一卷**。
- 一张杯贴约 **7 cm**；一卷 58×50mm 约 20 米 → **约 280 张**。
- **备货红线**：任一种低于 5 卷就补货；节假日翻倍备。
- 纸的存放：避光、防潮、30℃ 以下。热敏纸受潮会发黑、字迹变淡（顾客拿了小票两小时就看不见字，多半是纸的问题，不是打印机）。

### 2.5 摆放

- 离水槽、蒸柜、油锅至少 1 米：**热敏纸怕水怕油**，油污进纸仓会卡纸。
- 机器四周留 5cm 散热空间，别塞进密闭柜子。
- 放在平稳台面上：热敏打印靠走纸精度，机器抖会让字歪、条码扫不出。
- 电源线和网线走同一边，别横跨过道（绊一下就是一台机器摔地上）。
- 出纸口不要对着墙，留 15cm 让纸自然垂落。

## 三、电源与网络规划

### 3.1 目标拓扑

```
                    ┌──────────── 店里的路由器（192.168.1.1）────────────┐
                    │                                                    │
   收银电脑（跑后端）│         Zy307 小票机             打印服务器 + XP-236B │
   192.168.1.50 ────┤         192.168.1.100            192.168.1.101      │
        :8787       │              │ 网线                    │ 网线           │
                    └──────────────┴─────────────────────────┴──────────────┘
                              （全部有线，同一个网段）
```

要点：

- **三台设备必须同网段**（`192.168.1.x`），并且能互相 ping 通。
- 打印机**不连 Wi-Fi**：Zy307 只有网口，XP-236B 没有 Wi-Fi。别指望无线，热敏机掉线比网线多十倍。
- 收银电脑用网线接路由器，不要用手机热点。

### 3.2 IP 规划（建议照着做）

| 设备 | 建议 IP | 说明 |
|---|---|---|
| 路由器 | 192.168.1.1 | 网关，一般不用改 |
| 收银电脑（后端） | 192.168.1.50 | 在路由器里给电脑做静态绑定 |
| Zy307 小票机 | 192.168.1.100 | 网口直连，可在机器菜单或工具里设 |
| 打印服务器 | 192.168.1.101 | 用它的管理页设成静态 IP |

把 `.100–.149` 留给设备，`.50–.99` 留给电脑和手机，避免和 DHCP 池撞车。

### 3.3 怎么查打印机现在的 IP（四种方法，从准到不准）

1. **打自检页**（最准）：关机 → 按住 FEED 不放 → 开机 → 松手，纸上会印 `IP: 192.168.x.x`。
2. **打印服务器的管理页**：浏览器打开它的默认地址（说明书上写，常见 `192.168.0.10` / `192.168.1.10`），登录后能看到当前 IP。
3. **路由器后台**：找「已连接设备 / 客户端列表」，按品牌或 MAC 认（芯烨、ZYWELL 一般显示为打印机或 MAC 前缀）。
4. **电脑的邻居表**：在收银电脑上 `arp -a`，看最近通信过的地址。

### 3.4 把 IP 钉死（这一步不做，迟早出事）

DHCP 租约到期或路由器重启后，打印机可能换 IP——第二天早上两台机器一起不出纸，而配置一个字没改。

**通用做法（所有路由器都一样）**：路由器后台 → 找到「DHCP 服务器 / 地址保留 / 静态 IP 绑定」→ 把打印机的 **MAC 地址** 绑到一个固定 IP → 保存。

各家路径（以你家路由器实际界面为准）：

| 品牌 | 大致路径 |
|---|---|
| TP-Link 家用 | 路由器设置 → DHCP 服务器 → 地址保留 |
| 华为路由 | 更多功能 → 网络设置 → DHCP → 静态 IP 绑定 |
| 小米 / Redmi | 高级设置 → DHCP 静态 IP |
| 华硕 | 内部网络 → DHCP 服务器 → 手动分配 |

绑定的是 **MAC**，不是名字。MAC 在自检页上（`MAC: XX:XX:...`）。

### 3.5 端口与防火墙

| 方向 | 端口 | 谁连谁 | 说明 |
|---|---|---|---|
| 出站 | 9100 | 收银电脑 → 打印机 | RAW / JetDirect，两台都走这个 |
| 入站 | 8787 | 顾客手机 / 老板平板 → 收银电脑 | 后端网页端口 |

在收银电脑上验证（PowerShell，把 IP 换成实际值）：

```powershell
Test-NetConnection 192.168.1.100 -Port 9100   # 小票机
Test-NetConnection 192.168.1.101 -Port 9100   # 打印服务器 + 标签机
```

必须看到 `TcpTestSucceeded : True`。**IP 不通的时候，后面所有排查都是猜。**

放行网页端口（管理员 PowerShell 执行一次）：

```powershell
New-NetFirewallRule -DisplayName "湘村点单 8787" -Direction Inbound -LocalPort 8787 -Protocol TCP -Action Allow -Profile Private
```

手机打不开网页（但电脑能打开）——九成是这条规则没加，或者电脑连的网络被 Windows 认成了「公用网络」。

### 3.6 三个最常见的网络坑

| 坑 | 表现 | 怎么绕 |
|---|---|---|
| 2.4G / 5G 分成两个网段 | 手机连 5G，电脑在 2.4G，互相 ping 不通 | 关掉「双频合一分离」，或让手机连和电脑同一个 SSID |
| 访客网络 / AP 隔离 | 设备能看到路由器，但设备之间互访被拦 | 打印机和电脑都连主网络，别连 Guest |
| 商场 / 物业统一网络 | 9100 被禁用、设备隔离 | 自己拉一条独立宽带，或加一台小路由器做内网 |

## 四、接线：四种接法，选一种

### 4.1 方案 A（推荐）：Zy307 网口直连

**需要**：一条网线、路由器上一个空闲 LAN 口。

1. 关机。
2. 网线一头插 Zy307 背面的 **LAN** 口，另一头插路由器的 **LAN** 口（**不要插 WAN 口**，那是进户线）。
3. 开机，等 10 秒。
4. 打自检页，记下 IP（第 3.3 节）。
5. 在收银电脑上 `Test-NetConnection <IP> -Port 9100`，通了继续。
6. 路由器里做静态绑定（3.4）。

**验收**：端口通 + 老板端「打测试页」出纸且被切断。

### 4.2 方案 B（推荐）：XP-236B + USB 转网口打印服务器

**为什么必须这样**：XP-236B 只有 USB 和蓝牙。USB 直插 Windows 时，`\\.\USB001` 是个假设备节点，写进去打印机纹丝不动；只能装驱动走打印队列，而驱动那层有自己的初始化和数据转换，是「打半张、字变形」的头号来源。用打印服务器把 USB 转成网络打印，等于把这层不确定性整个拿掉。

**步骤**：

1. 打印服务器 USB 口 ← USB 线 ← XP-236B。
2. 打印服务器网口 ← 网线 ← 路由器 LAN 口。
3. 上电，等指示灯稳定（一般是 Power 常亮、LAN 闪烁）。
4. 找到它的默认 IP（说明书 / 机身标签，常见 `192.168.0.10`、`192.168.1.10`），浏览器打开管理页。
5. 在管理页里：
   - 网络：改成**静态 IP**，比如 `192.168.1.101`，网关 `192.168.1.1`；
   - 端口：**RAW / JetDirect，端口号 9100**（有的叫「TCP RAW」「端口 9100」）；
   - 保存并重启打印服务器。
6. 在收银电脑上 `Test-NetConnection 192.168.1.101 -Port 9100`，通。
7. `.env` 里标签机用：`KIND=net`、`HOST=192.168.1.101`、`PORT=9100`。

**验收**：管理页能看到「打印机已连接」，测试页出纸。

> 打印服务器的 IP 和打印机不在同一网段也没关系，只要后端能连上它就行；但**别跨 VLAN**，小店没必要给自己找麻烦。

### 4.3 方案 C（备选）：XP-236B 走 Windows 共享

**什么时候用**：打印服务器还没到货，先让机器出纸。

**前提**：收银电脑上装了 XP-236B 的驱动，并且打印机属性里开了共享。

1. 装驱动（芯烨官网下载 XP-236B 驱动；装的时候选「票据 / Receipt」而不是「标签 / Label」）。
2. 控制面板 → 设备和打印机 → 右键 XP-236B → 打印机属性 → **共享** → 勾「共享这台打印机」→ 共享名填 **`XP236B`**（**不要带空格和中文**）。
3. 控制面板 → 网络和共享中心 → 高级共享设置 → 启用「文件和打印机共享」。
4. 验证共享存在（PowerShell）：`Get-Printer | Select-Object Name, ShareName`。
5. `.env`：

```ini
PRINT_LABEL_KIND=system
PRINT_LABEL_QUEUE=XP236B
PRINT_LABEL_HOST=
```

**为什么代码里 Windows 用 `copy /b` 而不是 `print`**：`print` 是文本打印，ESC/POS 里的 `0x0C`（换页）、`0x0D`（回车）会被当控制字符吃掉——打出来是半张票或干脆空转。`copy /b` 是二进制原样拷贝，字节完整送到 spooler。这是老方案里最隐蔽的一个坑。

**验收**：老板端点「打测试页」能出纸，且小票是完整一张（不是半张、不是空白）。

**如果出纸但内容残缺**：说明中间那层驱动在改数据。别跟它较劲，换方案 B。

### 4.4 方案 D（应急）：蓝牙

只在「机器临时挪位置、网线拉不过去」时用。

1. Windows 设置 → 蓝牙 → 配对 XP-236B。
2. 设备管理器 → 端口（COM 和 LPT）→ 找到新增的「标准串行 over 蓝牙链接」，记下 COM 号（比如 COM5）。
3. `.env`：`PRINT_LABEL_KIND=usb`、`PRINT_LABEL_DEVICE=\\.\COM5`。
4. 该 COM 口波特率保持 SPP 默认（9600）。

**缺点**：只能一台电脑连；隔一堵墙就断；断线后要重新配对。属于「今晚先出纸」的方案，不用于长期。

### 4.5 选哪种？一张表决定

| 接法 | 稳定性 | 成本 | 维护 | 建议 |
|---|---|---|---|---|
| A 网口直连（Zy307） | ★★★★★ | 一条网线 | 几乎为零 | **默认选它** |
| B 打印服务器（XP-236B） | ★★★★★ | ¥60–120 | 几乎为零 | **默认选它** |
| C Windows 共享 | ★★★ | 0 | 驱动/共享会变 | 临时过渡 |
| D 蓝牙 | ★★ | 0 | 要重配 | 只应急 |

## 五、XP-236B 的第一道关：确认在「票据模式」

这一步没过，后面全白配。表现是：**老板端显示连上了、点打测试页，机器一声不响，什么也不出。**

### 5.1 为什么

XP-236B 是双模机：票据模式认 ESC/POS，标签模式认 TSPL。两个模式的指令集完全不兼容——在标签模式下收到 ESC/POS 字节，它会当成无效数据直接丢掉，连报错都没有。出厂可能停在任意一个模式，取决于批次和经销商。

### 5.2 打一张自检页

1. 关机（拔不拔电源都行，按面板关机）。
2. **按住 FEED 键不松**。
3. 开机，继续按住约 2 秒，等机器开始出纸再松手。
4. 它会打出一张自检页。

### 5.3 自检页看三样东西

| 看什么 | 怎么看 | 结论 |
|---|---|---|
| **模式** | 页头 / 页脚印着 `ESC/POS` 还是 `TSPL`、`Label`、`Gap` | 必须是 **ESC/POS** |
| **IP** | 有没有 `IP: 192.168.x.x` | 记下来，做静态绑定 |
| **MAC** | `MAC: XX:XX:...` | 路由器绑定用 |

如果自检页上写的是 TSPL / Label，先切模式，别急着配置。

### 5.4 切模式（三种办法，按顺序试）

1. **官方工具**：芯烨官网下载「打印机设置工具 / Printer Utility」，USB 连上机器，在「打印机模式 / Print Mode」里选 **票据模式（Receipt / ESC/POS）**，写入后重启机器。
2. **驱动安装时选类型**：重装驱动，在型号/用途里选「票据打印机 / Receipt」，不要选「标签打印机 / Label」。
3. **按键组合**：部分固件支持（比如关机按住 PAUSE + FEED 开机），**以随机说明书为准**，别乱试——试错可能把机器恢复出厂。

### 5.5 验收

- 老板端「打测试页」→ 机器立刻出纸；
- 纸上是中文（不是乱码、不是方块）；
- 一行 32 个字符左右，右边不被切；
- 杯贴上有桌号、菜名、时间、序号。

### 6.6 配开机自启（三选一）

#### 方式一：任务计划程序（最简单，推荐）

1. 开始菜单搜「任务计划程序」。
2. 右侧「创建任务」。
3. **常规**：名称 `湘村点单后端`；勾「不管用户是否登录都要运行」会要求输密码，图省事就选「只在用户登录时运行」。
4. **触发器**：新建 → 「登录时」→ 确定。
5. **操作**：新建 → 程序 `C:\Windows\System32\cmd.exe`，参数：

   ```
   /c cd /d C:\srv\xiangcun && npx tsx --env-file=.env apps/server/src/main.ts
   ```

   起始于：`C:\srv\xiangcun`
6. **设置**：取消勾「如果任务运行超过以下时间，停止任务」；勾「如果任务失败，每 1 分钟重启一次，最多 3 次」。
7. 保存，右键任务 →「运行」，确认网页能打开。
8. 重启电脑验证一次：不登录任何东西，等 30 秒，网页应该自己活了。

#### 方式二：NSSM 装成 Windows 服务（最稳，断电重启自动拉起）

1. 下载 NSSM（nssm.cc），解压到 `C:\srv\nssm`。
2. 管理员 PowerShell：

   ```powershell
   C:\srv\nssm\win64\nssm.exe install XiangcunServer "C:\Windows\System32\cmd.exe" "/c cd /d C:\srv\xiangcun && npx tsx --env-file=.env apps/server/src/main.ts"
   C:\srv\nssm\win64\nssm.exe set XiangcunServer AppDirectory "C:\srv\xiangcun"
   C:\srv\nssm\win64\nssm.exe set XiangcunServer AppStdout "C:\srv\xiangcun\logs\server.log"
   C:\srv\nssm\win64\nssm.exe set XiangcunServer AppStderr "C:\srv\xiangcun\logs\server.err.log"
   C:\srv\nssm\win64\nssm.exe set XiangcunServer Start SERVICE_AUTO_START
   C:\srv\nssm\win64\nssm.exe start XiangcunServer
   ```

3. 以后重启电脑，服务会自己起来，不用登录桌面。

#### 方式三：Linux（如果后端放在小主机 / NAS 上）

```ini
# /etc/systemd/system/xiangcun.service
[Unit]
Description=Xiangcun ordering server
After=network-online.target

[Service]
WorkingDirectory=/srv/xiangcun
ExecStart=/usr/bin/npx tsx --env-file=.env apps/server/src/main.ts
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now xiangcun
```

### 6.7 让手机能打开（局域网）

1. 查收银电脑的 IP：`ipconfig`，找「IPv4 地址」，比如 `192.168.1.50`。
2. 在路由器里给它做静态绑定（同 3.4）。
3. 管理员 PowerShell 放行 8787（命令见 3.5）。
4. 手机连同一个 Wi-Fi，打开 `http://192.168.1.50:8787/?table=12`。
5. 老板平板打开 `http://192.168.1.50:8787/admin/`。

> 桌贴二维码的地址要写成这个 IP。以后换电脑，二维码就得重印——所以先把电脑和 IP 定下来再印。

## 七、`.env` 参数完全手册

> 规则：**改完必须重启后端**。所有 `PRINT_*` 缺省 = 关闭，一台不配系统照常跑，只是不打纸。

### 7.1 基础

| 变量 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `BRAND` | 是 | — | 门店配置目录名，对应 `brands/<名字>/` |
| `DB_PATH` | 是 | `./data/app.db` | 数据库文件，一个文件 = 一整本账 |
| `BACKUP_DIR` | 是 | `./backups` | 每 10 分钟的本地快照目录 |
| `BACKUP_EVERY_MINUTES` | 否 | `10` | 备份间隔 |
| `UPLOAD_DIR` | 是 | `./data/uploads` | 菜品图存放，备份要一起备 |
| `API_PORT` | 否 | `8787` | 后端端口；手机访问也要用这个 |
| `ADMIN_PASSWORD` | 是 | — | 老板端密码，**至少 8 位** |
| `SERVE_STATIC` | 否 | 未设 | 设 `1` 时后端同时发顾客端和老板端网页（店里单机模式必开） |
| `LEGACY_DB_PATH` | 否 | — | 老系统数据库路径，设了就在启动时做一次迁移（幂等） |

### 7.2 小票机（Zy307）

| 变量 | 默认 | 取值 | 说明 / 踩坑 |
|---|---|---|---|
| `PRINT_RECEIPT_ON` | `0` | `0` / `1` | 总开关。**先关着**，测试页通过再开 |
| `PRINT_RECEIPT_KIND` | `mock` | `net` / `usb` / `system` / `mock` | 网口填 `net`；`mock` 只留记录不出纸 |
| `PRINT_RECEIPT_HOST` | — | IP | `net` 必填 |
| `PRINT_RECEIPT_PORT` | `9100` | 整数 | 网口机几乎都是 9100 |
| `PRINT_RECEIPT_PAPER` | `80` | `80` / `58` | 填错会截边或挤成一团 |
| `PRINT_RECEIPT_CUTTER` | `1` | `0` / `1` | Zy307 有切刀填 1；无切刀填 1 会空吐纸 |
| `PRINT_RECEIPT_DRAWER` | `0` | `0` / `1` | 接钱箱（RJ11）才填 1，打小票会弹钱箱 |
| `PRINT_RECEIPT_ENCODING` | 兜底 | `gbk` / `gb18030` / `utf8` | 留空用 `PRINT_ENCODING` |
| `PRINT_RECEIPT_QUEUE` | — | 文本 | 仅 `KIND=system`：Windows 共享名 / Linux 队列名 |
| `PRINT_RECEIPT_DEVICE` | — | 路径 | 仅 `KIND=usb`：Linux `/dev/usb/lp0`，Windows 蓝牙 `\\.\COM5` |

### 7.3 标签机（XP-236B）

| 变量 | 默认 | 取值 | 说明 / 踩坑 |
|---|---|---|---|
| `PRINT_LABEL_ON` | `0` | `0` / `1` | 同上 |
| `PRINT_LABEL_KIND` | `mock` | 同上 | 打印服务器 = `net` |
| `PRINT_LABEL_HOST` | — | IP | 打印服务器的 IP |
| `PRINT_LABEL_PORT` | `9100` | 整数 | — |
| `PRINT_LABEL_PAPER` | `58` | `80` / `58` | XP-236B 必须 `58`；填 80 右边被切 |
| `PRINT_LABEL_CUTTER` | **`0`** | `0` / `1` | **没有切刀，必须 0** |
| `PRINT_LABEL_BIGTABLE` | `1` | `0` / `1` | 桌号三倍字（1，远看清）/ 两倍字（0，省纸） |
| `PRINT_LABEL_ENCODING` | 兜底 | `gbk` / `gb18030` / `utf8` | 两台可以不一样 |
| `PRINT_LABEL_QUEUE` / `DEVICE` | — | — | 同小票机 |

### 7.4 公共

| 变量 | 默认 | 说明 |
|---|---|---|
| `PRINT_ENCODING` | `gbk` | 两台都没单独配时的兜底编码 |
| `PRINT_RETRIES` | `2` | 失败重试次数（不含第一次） |
| `PRINT_BACKOFF_MS` | `1500`（模板值；不填时代码内是 800） | 首次重试间隔，之后翻倍 |

### 7.5 编码怎么选

| 值 | 什么时候用 |
|---|---|
| `gbk` | 国产热敏机默认，芯烨 / ZYWELL / 佳博基本都吃这个 |
| `gb18030` | GBK 超集，菜名里有生僻字（犇、麤）不丢字，字节长度不变 |
| `utf8` | 少数外贸机；**填错会整段乱码** |

系统在发中文前会先发 `FS &`（进入汉字模式）。这一条不做的话，机器可能把「湘」拆成两个乱字符，而且**有的单正常、有的单乱**——这是最难查的一类。代码已经处理了，不用你在机器上设置。

## 九、日常操作

### 9.1 开档（3 分钟）

1. 确认两台机器电源灯亮、无红灯。
2. 看一眼纸：小票纸剩多少、标签纸剩多少。
3. 打开老板端「打印设置」，两台都应是绿色/在线。
4. **每周一（或前一天出过问题）点一次「打测试页」**，比等到第一单再发现强。
5. 确认收银电脑没睡眠、没关机、没开代理/VPN。

### 9.2 接单出纸

顾客点「下单」→ 老板端「实时订单」响提示音、出现新单 → 两台机器同时出纸。

出纸后核对三处：单号（`1029-034` 这种）、桌号、金额。加菜单的单号带 `A1`。

### 9.3 补打（纸没出来 / 打印模糊 / 顾客要一张）

1. 老板端 →「实时订单」→ 找到那一单。
2. 点「补打小票」（这张单再打一张前台小票）或「补打杯贴」（这张单的每杯饮品各打一张）。
3. 去机器那边看纸出来没有；出来后会多一条打印记录。

**不要为了补一张纸重新下单**——会多一单、多扣一次库存、金额也算两遍。

### 9.4 换纸

**Zy307（80mm 小票纸）**

1. 按面板开盖键（或掀盖），取出旧纸轴。
2. 新纸卷放进纸仓，**热敏面朝下、朝打印头**（用指甲在纸面上划一下，变黑的那面是热敏面）。
3. 纸头拉出约 10cm，盖上盖子，听到「咔」一声。
4. 按 FEED 走纸 2 秒，确认走纸顺、不歪。
5. 老板端点「打测试页」确认。

**XP-236B（58mm）**

1. 掀开上盖，取出旧卷。
2. 新卷放入，同样**热敏面朝打印头**，纸头从出纸口穿出。
3. 压下上盖，两侧卡扣都扣紧（没扣紧会报「盖子打开」）。
4. 按 FEED 走纸，确认不卡、不歪。
5. 打测试页。

> 换纸后第一张如果字淡：多半是纸装反了。停机、翻面、重来。

### 9.5 清洁（每月一次，或出现竖条纹时）

1. **断电**（不是待机，拔插头）。
2. 用无水酒精棉签，**单方向**轻擦打印头（那条发亮的金属线），不要来回蹭、不要用力压。
3. 擦胶辊（黑色橡胶轮），把纸屑、油污擦掉。
4. 纸仓里的粉尘倒掉，别用嘴吹（口水进光路）。
5. 等酒精完全挥发（1 分钟）再通电。

出纸有竖向白条、字缺笔画——九成是打印头脏了，不是坏了。

### 9.6 耗材管理

- 小票纸、标签纸各备 **≥10 卷**，低于 5 卷补货。
- 只用正规热敏纸：劣质纸掉粉堵头、字两天就褪、还会让切刀变钝。
- 纸卷别放窗边晒、别放灶台边烤。

### 9.7 打烊

- 打印机可以一直通电（待机功耗很低），也可以断电；**断电后第二天要重新确认在线**。
- 收银电脑**不要关机**（关了第二天要等人来开）；设成「从不睡眠」即可。
- 长期停业（>3 天）：断电、拔插头、纸卷取出（防潮）、盖防尘布。

### 9.8 周检 / 月检

| 周期 | 做什么 | 谁做 |
|---|---|---|
| 每周一 | 两台各打一次测试页；看打印记录有没有失败 | 店长 |
| 每周 | 检查纸库存；擦一次出纸口灰尘 | 店员 |
| 每月 | 酒精清洁打印头 + 胶辊；检查线缆有没有被压/被踩 | 店长 |
| 每季 | 备份数据库拷一份到 U 盘/网盘；检查路由器固件 | 技术 |

## 十、故障排查

### 10.1 三分钟定位法（按顺序，别跳步）

```
① 机器本身的灯和纸  →  红灯/缺纸/盖子没关？先解决这个
② 网络通不通        →  Test-NetConnection <IP> -Port 9100
③ 配置对不对        →  打印设置页显示「未启用」= .env 没开或没重启
④ 机器认不认指令    →  打自检页看是不是 ESC/POS（仅 XP-236B）
⑤ 打测试页          →  出纸 = 链路通；不出 = 回 ①–④
⑥ 看打印记录        →  失败原因写得比人话还清楚
```

### 10.2 现象 → 原因 → 动作

| # | 现象 | 多半是 | 怎么改 |
|---|---|---|---|
| 1 | 两台都不出纸，页面正常 | 收银电脑关机/睡眠，或后端没起来 | 打开网页看能不能访问；重启服务 |
| 2 | 两台都不出纸，网页也打不开 | 后端挂了 / 端口被防火墙拦 | 看 `logs/server.err.log`；放行 8787 |
| 3 | 一台出、一台不出 | 单台配置或网络 | 单独点那台的「打测试页」，照 10.3 查 |
| 4 | 显示「未启用（在服务器 .env 里打开…）」 | `PRINT_*_ON=0` 或改完没重启 | 改 1，重启后端 |
| 5 | 显示「连不上：机器没开机，或者 IP 填错了」 | IP 错 / 机器没开 / 不同网段 | `ping` 一下；核对 IP；看是不是换了网段 |
| 6 | 显示「机器没回话：检查电源、纸装好没有、盖子关紧没有」 | 网线通但机器忙/缺纸/盖开 | 看面板灯；装纸；压紧盖子 |
| 7 | 显示「网线通了（这只是基础检测…）」 | 只是 TCP 通，不代表能打 | 点「打测试页」，别把它当成功 |
| 8 | 测试页不出纸，但状态通 | **XP-236B 还在 TSPL 标签模式** | 第 5 章，切票据模式 |
| 9 | 打出来全是乱码 / 问号 | 编码不对 | 改那台的 `*_ENCODING=gbk`；还乱试 `gb18030` |
| 10 | 中文正常，偶尔几个字变问号 | 生僻字超出 GBK | 改 `gb18030` |
| 11 | 右边被切掉半截 | 纸宽填大了 | 58mm 机器填 `58` |
| 12 | 字特别小、一行挤很多 | 纸宽填小了 | 80mm 机器填 `80` |
| 13 | 出纸后不切、拖着走 | 没切刀或 `CUTTER` 填反 | XP-236B 填 `0`；Zy307 填 `1` |
| 14 | 标签机空吐一段白纸 | 给无切刀机器发了切纸指令 | `PRINT_LABEL_CUTTER=0` |
| 15 | 打半张就停 | Windows 共享走了文本打印（`print`） | 代码已改 `copy /b`；仍不行就换打印服务器 |
| 16 | 同一单打了两张 | 重复点击/重复下单；或两台都配了同一台机器 | 看打印记录的时间戳；核对 `.env` 的 HOST |
| 17 | 早上一来两台都不出纸 | IP 变了（没做静态绑定） | 3.4，绑 MAC |
| 18 | 页面要等好几秒才出来 | 机器没开机，状态探测在等超时（每台 5 秒，两台并行） | 正常现象；开机后点「重新检测」 |
| 19 | 打印记录里有一堆失败 | 之前机器离线/缺纸 | 逐条补打；改成现在这样后再观察一天 |
| 20 | 字迹越来越淡 | 纸受潮 / 打印头脏 / 浓度设置低 | 换纸；清洁打印头；机器菜单调浓度 |
| 21 | 条码扫不出 | 打印浓度低 / 纸太差 / 条码太小 | 调浓度；换纸；不要缩印小票 |
| 22 | 顾客端能下单，但后厨没单 | 不是打印问题 | 看「实时订单」有没有这张单；没有就是下单失败 |

### 10.3 深入排查

#### 10.3.1 网络层

```powershell
ping 192.168.1.100               # 通不通（ICMP 可能被机器关掉，别只信这个）
Test-NetConnection 192.168.1.100 -Port 9100
arp -a | findstr 192.168.1.100   # 看 MAC 对不对
```

- ICMP 不通但 9100 通：正常，很多打印机不回 ping。
- 9100 不通但 ping 通：端口没开/打印服务器没设成 RAW。
- 两个都不通：IP 错、不在同网段、线没插对、路由器隔离。

#### 10.3.2 编码层（乱码）

1. 先确认那台机器是 `gbk`（打印设置页会显示两台各自的编码）。
2. 还是乱 → 改 `gb18030` 重启试。
3. 变成方块/问号 → 说明机器不认这个编码，换 `gbk`。
4. 中文正常但英文数字乱 → 罕见，通常是纸/头问题，先清洁。

#### 10.3.3 排版层（截断/挤）

- 58mm：`PAPER=58`，一行 32 半角；80mm：`PAPER=80`，一行 48 半角。
- 长菜名会自动折行（代码里按显示宽度算，中文算 2 格）。
- 如果整张都挤在左边 → 检查是不是填成了 `58` 但装的是 80mm 纸。

#### 10.3.4 通道层

| `KIND` | 排查点 |
|---|---|
| `net` | IP/端口/防火墙；打印服务器是否设成 RAW 9100 |
| `usb` | Linux 才有 `/dev/usb/lp0`；Windows 只能蓝牙 COM，见 4.4 |
| `system` | Windows 共享是否开启、共享名是否一致、`Get-Printer` 能否看到 |
| `mock` | 不出纸是正常的（演练模式），改回 `net` |

### 10.4 什么时候该找技术 / 换件

- 自检页都打不出来 → 机器硬件问题，联系卖家。
- 换过网线、换过口、换过打印服务器仍不通 → 网络问题，找拉网的人。
- 打印头竖条纹清洁后仍在 → 打印头老化，换机器。
- 切刀切不断/异响 → 切刀组件磨损，联系售后（别自己拆）。

## 十二、已知限制（先说清楚，免得到时候以为是 bug）

- **只用票据模式打杯贴，不做 TSPL 模切排版**。现在杯贴是 ESC/POS 打在 58mm 连续纸/普通热敏纸上。如果你要「40×30 模切标签、每张精确停在缝上、带条码区」，那需要 TSPL 整套指令和间隙校准，目前没做。
- **Windows 没有 USB 直写节点**。`\\.\USB001` 是假的，写进去不出纸。要么打印服务器（推荐），要么共享，要么蓝牙。
- **蓝牙只算应急**，断连、慢、只能一台电脑连。
- **后端上云 = 不能局域网打印**。除非以后加一台店里的「打印代理」。
- **状态检测只到「通/没回话/缺纸/开盖」**。USB 和共享通道只能验证「写得进去」，验证不了纸上到底有没有。
- **版式固定**，招牌、条码、字号都在代码里。想改版式要改 `templates.ts`，不是配置项。
- **不打印菜品图片**，小票是纯文字 + 条码。
- **单店两台**。多店多机需要按店路由到不同打印机，目前没做。

不接真机也能验版式：

```powershell

```

跑打印模块测试：

```powershell
npx vitest run apps/server/src/print
```

几个关键设计（改之前先看注释）：

- **先发 `ESC @` 再发 `FS &`**：不显式进汉字模式，部分机型会按单字节处理中文，表现为「有的单正常、有的单乱」。
- **纸宽按配置走**：58mm = 32 半角列，80mm = 48 半角列，中文占 2 列。
- **无切刀机器不发 `GS V`**：发了就空吐纸。
- **Windows 共享用 `copy /b`**：`print` 会吃掉控制字符，打半张。
- **两台各配置各的**：纸宽、编码、切刀、钱箱都独立，互不影响。
- **打印不阻塞下单**：订单落库后异步分发，失败只记日志。
