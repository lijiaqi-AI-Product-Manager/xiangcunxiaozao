## 二、军师 56号我没照做的部分（独立判断）

1. **「全站彩色清零」没有一刀切**：绿色的英文标签（CHEF'S PICKS 这类）是 41号批准的结构色，而且高斯上一轮原话点名保留「绿色的 CHEF'S PICKS」；饮品区滑到时背景转淡青绿是 43–49号批准的。这两类我保留了，写进色彩审计表「保留的」一栏请确认。高斯这次说的不要绿 / 蓝，我理解是针对「我的」页那几块——新页面里我自己加的绿、蓝、粉已经全部去掉（墨绿顶卡、莫兰迪四格、取餐「请取餐」的绿、退款 / 加值的绿字）。
2. **功能格没有用深棕底 + 白字**：军师建议赭石 / 陶土 / 茶褐 / 驼色四块深色。四块深棕压在宣纸底上会很闷、和黑金顶卡抢；我用的是同色系浅一档的渐变 + 墨字，只让「会员储值」一格黑金，层级更清楚。如果高斯想要更深，换 token 即可。
3. **卡面没加新字**：军师稿里的「湘村小灶 · Xiangcun Xiaozao」「湘·村·小·灶·会·员」是新文案（英文店名还会把店名写进代码），没加。卡上只有已有的字：储值余额、会员号、打码手机号、店名、SIGNATURE。
4. **鎏金不是亮黄**：主金 #C9A257（低饱和哑光），渐变到 #E6C988 / #B8964F，没有高光扫过。

## 五、我自己发现的问题

1. 会员卡四档色板第一版里，土黄金卡、黄金卡底部最暗处字的对比度不到 4.5，余额渐变最暗的一档 4.23——已经调亮重测（见第四节）。
2. 功能格的副字（「2 单」「待提供」）在赭金、驼色那两格的深端第一版只有 3.6 / 4.1——改成更深的墨色重测。
3. 登录按钮在没填完时整体变淡太多，像一块死字——改成 .78。
4. 「我的订单」列表里「已取消」会被拆成「已 / 取消」两行——状态字改成不拆。
5. 购物车弹层太透，后面的菜名透上来抢字——弹层改到 95% 纸白。
6. 大画小标签名字长时，以前是把名字挤小，现在价格会换到下一行（名字永远一行），小标签变成两层高——如果高斯更喜欢永远一层，可以改成长名字时省掉价格。
7. 黑金卡上的红色双环章，环缝用了卡底色；在土黄金 / 黄金卡上红章比较跳，等定了色板再微调。
