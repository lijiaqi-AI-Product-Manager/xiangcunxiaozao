### 第二批三页

- **取餐**：三重编码 = 衬线大字取餐号 + 下面一行兜底数字（No. 001）+ 叫号语音（顾客点「开启叫号语音」后，状态到「请取餐」时念一遍取餐号）；状态本身也是 图标 + 文字 + 颜色。三段进度 已下单 / 制作中 / 请取餐，当前段有个呼吸点。状态一变，号码牌绕横轴翻一下（只动 transform）。已取消 = 整张卡变灰去饱和。桌号、下单时间、付款方式改成小胶囊，不做「标签：值」一行行的表单
- **会员**：会员卡 = 大画态那个「湘味油泼牛肉 RM 48」小标签放大（白底大圆角 + 朱砂红余额 + 柔投影 + 金棕书签条，浮在水墨上）。储值规则只用批准过的文案；消费记录最近 3 条（书法类型 + 黑体正文），多了可以展开
- **我的**：深墨绿顶卡（会员状态 + 退出登录在第一屏，卡上压一行书法店名做装饰位）+ 莫兰迪 2×2（我的订单 / 门店信息 / 会员储值 / 常见问题，同色系渐变 + 微立体图标，点了滑到对应那一块）；门店信息是三个小卡；问答折叠用圆环箭头
- **结算**（表里没列，按同一套语言推导）：01 核对菜品 / 02 桌号与备注 / 03 付款方式三块纸白面板，大圆角输入框，辣度胶囊，付款方式圆角选项卡
- **Dock**：浮动墨玻璃胶囊 + 药丸选中态；四页切换只淡入，不推挤

### §2.2 今日招牌（后台可配）

- 存在已有的 `settings` 表里（新键 `home.today`，只存菜品 ID 列表）——**没改表结构**
- 新加两个接口：顾客端只读 `GET /api/store/today`；老板端 `GET/POST /api/admin/today`（最多 5 道、不能重复、不卖的菜拦住）
- 老板端「菜品管理」页顶部加了「今日招牌」面板：每道菜后面有「设为今日招牌」，面板里能上移 / 下移 / 移出
- 图、菜名、价格都从菜单现读：老板改价、换图，大画和横幅卡自动跟着变；下架或今日售罄的不上大画
- 没设置时，顶部只有门店框，不出大画

## 三、我自己发现的问题（对照 38号 §9.9 十二条 + 规格字面）

1. **点按小印比以前淡**：按规格 1px 细环 + .85 做出来，28px 的小印在手机上偏浅（对比图问题一可以看到）。如果想更醒目，可以细环 1.5px 或透明度 .9——需要拍板。
2. **第一组「招牌菜」跳转时样子和别的组不一样**：有大画时，240px 触发线（规格不变）比分类条吸顶（约 270px）早，第一组没法在「收起态」下正好贴住分类条。现在的办法是停在触发线前一点（不收起），标题照样贴在分类条下沿 8px，误差 0；但这时横幅卡不会落下。
3. **滚动联动高亮没有用 IntersectionObserver**：分类条收起时会下移 102px、吸顶前还跟着内容走，固定位置的观察线跟不上，会亮错。改成滚动时每帧读一次分组位置（十几个数，很轻），结果准。和规格字面不同，特此说明。
4. **高亮 2.4s 缓动只用在「滚出来的」高亮上**：手点分类那一下改成 0.2s 立刻亮，否则点了要等两秒多才亮，像没反应。
5. **结算页是推导页**，规格说要先截图给军师过一眼再继续；因为这次要求两批做完一起交，没有单独先过目，请这次一起看（截图 09）。
6. **今日招牌和「不碰 API 契约」字面冲突**：§2.2 要后台能改，就必须新加接口；已有接口一个没动、表结构没动。改动集中在服务端 2 个文件 + 老板端 1 个文件 + 契约 1 个类型。
7. **叫号语音要顾客先点一下**才能出声（浏览器规定），所以是「开启叫号语音」按钮；iPhone 静音键开着时不会响。
8. **储值规则内容很少**：批准过的文案只有问答里那一条 + 「充值和调整请到柜台办理」，没再编。会员卡、取餐页也没加英文标签（新英文要批准）。
9. **大水印 7% 压在面板前面**，在取餐号卡、会员卡这种大块白底上看得比较清楚（截图 11、15）；如果嫌「脏」，可以只在点单页前置，其他页放回背景。
10. **门店信息全是「待提供」**：地址、电话、营业时间品牌配置里还是空的（不编），「我的」页门店小卡和功能格副字都显示「待提供」。
11. **开不了 PR**：仓库没有远程地址；三批做成三个叠加的分支，回退要按 3 → 2 → 1 的顺序。

38号 §9.9 十二条逐条：大面积死平纯色 —— 无（宣纸渐变 + 墨晕 + 纸纹）；白底灰框堆卡片 —— 无（纸白轻透面板 + 顶边光）；表单化 Label-Value —— 取餐信息改胶囊、门店信息改小卡，结算页的输入框是真表单，按圆角浅玻璃处理；黑三角箭头 —— 全部换成圆环箭头；一屏 ≤ 3 道 —— 无（5–7 道）；俗气大红大面积 —— 无（朱砂只在价格、按钮、印章）；卡片全同无主次 —— 会员卡 / 顶卡 / 功能格 / 面板三级；工具感无光效 —— 有边缘光、柔投影、落点柔光；信息堆砌 + 营销噪音 —— 无（没有新文案）；灰暗线性图标全家桶 —— 面性 + 微立体；小圆角 —— 全部 ≥ 16px（印章、书签条豁免）；无动效 —— 有常驻呼吸 + 微反馈，减弱动态效果全降级。
