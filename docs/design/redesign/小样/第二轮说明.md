## 〇、先拍板：42号放行的「图料」是旧版 108 张图包，和最早的红线冲突

42号说 `assets/` 和 `images_test/` 里有已验收的成品图，可以填进设计稿。我在这台电脑上找到了 `D:\assets`，逐个文件比对后发现：

| 事实 | 说明 |
|---|---|
| `D:\assets` 和旧版源码里的 `web/assets` **完全相同** | 109 个文件逐个算校验值，全部一致（108 张图 + 1 个清单） |
| 数量正好 108 张 | 就是最早总提示词里的硬约束「❌ 用旧 108 张手绘图包」 |
| 清单写明 2026-10-14 生成，风格「深墨绿底 #1E3A3A / 粗深棕描边 / iPad 手绘高饱和」 | 是为旧版深绿主题出的图 |
| 42号点名的 R02、M0、P01 也在这包里 | 没有单独的 `images_test/` 文件夹 |

42号的理由是「那条红线只禁生成新图，不禁用已有的图」，但最早的禁令是**专门点名这包图**的，和「禁止抢跑出图」是两条不同的规矩。这个我不能自己定，所以**第二轮小样里一张图都没放**，图料位已经做好（见第二节），批准后改一行配置就能换上真图。

另外看了几张样图，提醒一下观感：菜品图是**深墨绿方底**上的半写实菜，R02 是**深蓝夜空**下的高饱和卡通插画。放在淡黄纸底上会是一块块深色方块，和水墨意境不是一个画风；23号 §5.3 也说过不要矢量插画的规整感。真要用，可能需要先去底或重新调色。

## 三、我自己发现的问题（6 条）

1. **图料冲突**（第〇节）：这是本轮最大的事，等拍板。
2. **墨晕 55% 和文字的平衡**：墨晕主要压在门店卡和分类条后面，菜卡是白色毛玻璃，所以菜名价格不受影响（对比度检查全过）；但菜卡之间的缝隙能看到墨团，有人会觉得「脏」。手机上看一眼再定浓度。
3. **「分类字标缩小 20%」我理解成详情页的区块方块字**：如果指的是分组标题旁的英文小字（现在 11px），再缩 20% 就看不清了，所以没动。请确认。
4. **缩略图墨痕在 64px 里偏重**：书法首字后面的干笔痕在小图里有时像「擦不干净」，可以再淡一档或只在大图用。
5. **私密网页里不能用地址参数切档位**：网页环境不传地址后面的参数，所以手机上看到的是自动判定的档位（好手机是 normal 全效果）；想看省电档要在电脑上打开本地文件加 `?tier=lite`。
6. **首字重复、印章次数**：上一轮报告里的两个问题还没拍板，本轮照旧。
