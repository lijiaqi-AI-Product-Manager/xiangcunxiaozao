## 一、高斯原话 → 落点

| 原话 | 做了什么 |
|---|---|
| 形状尽量椭圆 / 圆角长方形，去结算要和后面的毛玻璃板同形 | 上一版已做：去结算圆角长方形（20 / 22px），托盘 23px、Dock 26px，同一家族 |
| 加减按钮不要近直角方块，要圆形 | 上一版已做：正圆，视觉 32px、触控 44px |
| **店名框、分类条、菜品白底栏目、加减那一块「稍微透一点点」，毛玻璃，注意光和每块透多少** | **纸白毛玻璃**：店名框 72%、列表 68%、分类条 70%、算盘珠 84%、横幅卡 80%（数字越小越透）。每块都有顶边 1px 亮光、左边一丝亮光、极细噪点、左上极淡暖光。先按 78% 做，截图里和原来的白板几乎看不出区别，又往下透了一档——现在列表后面的墨晕和背景大水印能隐约看到 |
| 价格、菜名、分类、底部点单会员等用同一种有辨识度的书法（菜前面首字那种就不错） | 汉字用马善政（就是首字缩略那款）：菜名、分组标题、分类、页签、去结算、桌号、等待时间、店名 |
| **数字和英文不要书法（太丑），CHEF'S PICKS 那种除外** | 「RM 48」「RM 96」「16 分钟」「桌 8」、角标数字都换成和 CHEF'S PICKS 同一家的衬线体（Cinzel）。做法：同一个字体名下，数字英文自动走衬线、汉字走书法，不用逐处改；菜名里的「100 Plus」「Tiger」也是衬线 |
| 分类字大 1–2 号 | 15 → **17px** |
| 店名、明厨亮灶再醒目一点 | 店名 22 → **24px**，招牌三句 14 → **16px** |
| 底部页签大一号 | 13 → **14px** |
| 详细介绍、源流、食材正文用楷体，字号不变，标题保持 | 详细介绍、源流、工序、食材说明换楷体；区块标题粗黑不动（见第三节手机字体的问题） |
| **手机上湘村小灶水印被面板挡死** | ① 底：面板透了以后，背景那四个大字在列表右侧能隐约看到（默认版本就有）；② **A：水印进大画卡**，大图左下竖排，灰墨 9%，和 SIGNATURE 并排像画册落款；③ **B：并入门店框右下**，灰墨 10%，不占高度。「前置到内容上层」没做（会压字） |
| **大画态卡片贴着屏幕边，看不出是卡** | 左右各留 **14px**，圆角 20px + 边缘光 + 轻投影，浮在纸上；收起后的横幅卡同步 14px |
| 小标签做得像会员卡，保留 | 原样不动（白 72% + 柔投影），已记档为以后会员卡的样式基准 |

## 三、要你定（2 件）

1. **手机上的楷体**：电脑上有系统楷体，所以截图里是楷体；但**小米、iPhone 默认都没有楷体**，手机上详情正文会退成宋体。要手机上也是楷体，需要像书法字体一样自托管一款开源楷体并按正文用字裁剪——我建议用 **霞鹜文楷（LXGW WenKai，SIL 开源协议，可商用）**：从作者的 GitHub 发布页下载原字体（约 20MB），按详情正文实际用到的字裁成小文件（估计几百 KB）。下载需要你同意。
2. **水印 A / B 选哪个**：A 只在大画态出现；B 在默认版本出现，但只有约 375 宽以上的手机放得下，**360 宽的窄屏会自动不显示**（宁可不出也不压字）。独立的「落款带」我试了 48–64px，都会把首屏挤到 5 道，所以没采用。我倾向 **A + 面板透出兜底**。

## 四、我自己发现的问题（4 条）

1. **墨玻璃页签字投影偏重**：字放大到 14px 后，规格投影只有 4.2–4.5，加浓到 5px / 85% 才过 4.54。暗玻璃上看是一圈深晕，手机上如果觉得「糊」，就得把 Dock 透明度回调一点。
2. **托盘合计「RM 96」4.71**：改衬线后笔画比书法细，对比度从 5.6 降到 4.7，仍过线。
3. **面板透了以后，列表后面的大水印「湘村小灶」会透出来**——这正是想要的，但它是固定在屏幕右侧的，滚动时字不跟着走，像透过玻璃看到的远景。
4. **价格朱砂保持加深后的 #B02A21**（原 #C8372D 在纸白卡上贴线）；颜色比原来稍暗一点。
