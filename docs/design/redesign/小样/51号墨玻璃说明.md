## 二、实测

| 项 | 结果 |
|---|---|
| **玻璃上文字对比度（含投影）** | 新方法：页面背景换成纯白（玻璃后面最亮的情况），拍一张「文字隐藏」的图，取每段字底下「玻璃底 + 投影」的实际颜色和字色比。托盘：RM 96 = 5.44、去结算 = 9.57；Dock：取餐 5.11、会员 4.59、我的 4.62；V1：去结算 9.21、RM 96 9.63。**最低 4.59，过 4.5** |
| 其他文字对比度 | 最低 4.74（详情页，和上轮一样） |
| 结构五判（截图能验的部分） | 托盘、Dock：135° 渐变 ✓、静态光斑 ✓、滤镜值 ✓、不均匀边缘光 3 条内阴影 ✓、噪点层 overlay ✓；玻璃上常驻移动高光 **0** ✓；列表卡片背景模糊 **0** ✓ |
| 主线程动画 | 点单页、详情页、大画态页都是 0；动画属性只有 opacity、transform |
| 低配帧率（CPU 限速 6 倍） | 最终配置连跑 3 次：连点加购 56–58 帧、最慢一帧 33 / 50 / 50ms、超长帧 0；滚动 59–60 |
| 一屏 ≥ 6 道 / 触控 / 字号 / 减弱动态 / lite | 全过（同上轮） |

**验收五判里截图验不了的三条**（以高斯手机为准）：① 景深——托盘下面的菜名「认不出字、看得出形」；② 流动——从湘菜区滚到饮品区，透过玻璃能看到底色从暖变冷；⑤ 的「颗粒感」在手机高像素屏上才看得出来。

## 三、我自己发现的问题（5 条）

1. **列表卡片其实一直带模糊**：规格写「继续禁」，但代码里卡片从第一轮起就有 16px 背景模糊（低端机滑动掉帧的隐患），这次才去掉。卡片去模糊后，透过卡片看到的墨晕是清晰的（白 80% 压着），观感比之前稍「平」一点。
2. **Dock 页签字没完全照规格**：规格投影在 Dock 那一档透明度下只有 3.6–4.0，改成纯白字 + 稍深投影才过 4.5。要么接受这个加深，要么 Dock 透明度回调一点。
3. **Dock 降了两档**：14px 模糊 + 去饱和度——Dock 透出来的颜色会比托盘「灰」一点（饱和度没拉回来）。如果高斯觉得 Dock 不如托盘通透，可以反过来试「Dock 保饱和度、模糊降到 12px」。
4. **落点柔光很轻**：按规格参数（最亮 .35），落在红色角标上几乎只是一闪；要更明显可以把起始透明度提到 .5 或光斑放大。
5. **对比度测法换了**：之前的检查脚本看不到投影，这次对玻璃上的字改成「白底实拍」，更接近真实（也更严格：用纯白当玻璃背后的底）。其他地方的文字仍用原算法。
