## 二、我对「大图位放实物图」的看法

放实物图更好。理由：① 详情页的任务是让人想点这道菜，实物图（或手绘图）比书法更直接；② 你喜欢的那组设计（竖排英文 + 书法 + 浓墨 + 印）放到标题位置一样成立，而且不会被照片压住、对比度更稳；③ 没图的时候大图位是一片水墨 + 慢慢飘过的云影，不算空。等军师的宣纸底图到了，`images.json` 写一行就换上。

## 四、需要定 / 我自己发现的问题

1. **老板端选大画卡**是生产功能（B 线）：老板端要能挑菜、排顺序、以后加「特价」「小广告」两种卡。特价价格、广告内容我不能编，到时候需要你给规则和素材。这一块会动数据（新增一张「首页大画」配置），按红线要先批准再做。
2. **大水印压在面板前面**：7% 浅墨在字上几乎看不出，但在白处很清楚；如果手机上觉得「脏」，可以降到 5%。
3. **霞鹜文楷原字体 25MB 进了仓库**（和马善政、Cinzel 的原字体一样放在 `fonts/source/`，按 40号「保留字体源文件」）。如果嫌仓库变大，可以改成「构建时按固定版本 + 校验值下载」，不进仓库。
4. **点按印章用的是圆印**（和店标同形，小一号）；如果更想要方印，改一个类名的事。
