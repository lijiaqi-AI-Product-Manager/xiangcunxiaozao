## 三、我自己发现的问题（6 条）

1. **发布版顶部的版本链接条会把大图往下推约 44px**，所以在私密网页上横幅卡会比大图底边早一点点出现；设计稿本身没有这排链接，触发线正好在大图底边。
2. **横幅卡现在是水墨首字占位**（和列表缩略图同一个「油」字），图到了自动换真图；在那之前横幅卡的「图」不太像图。
3. **连点加号偶尔有一帧 67ms**：每道菜第一次加购时，要新长出算盘珠容器（带背景模糊的新图层），6 倍降速下偶尔慢一帧。真手机上大概率无感；要压到底可以让容器提前存在、只淡入，下轮可以做。
4. **淡绿底版的湘菜区墨色仍是赭石**：分区色温是「湘菜暖 / 饮品冷」，和底色无关，所以淡绿底上远山是赭石色。要不要淡绿底整体改青绿墨，请定。
5. **墨玻璃 75% 在截图里透得太清楚**（无头浏览器不做模糊）——上轮已提，仍等高斯手机确认。
6. **进店那一屏 3 层毛玻璃到线**：大图上浮着门店卡、价格锚两块玻璃，下面是分类条。再加任何玻璃元素就超了。
