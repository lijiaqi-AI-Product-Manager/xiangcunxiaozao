## 二、41号三条附加要求

### ① 低配模拟帧率（normal 档，全部效果打开）

条件：CPU 限速 6 倍、360×780、2 倍像素；毛玻璃、光源漂移、墨晕视差、落印全开。

| 场景 | 帧率 | 最慢一帧 | 卡顿帧（>50ms） |
|---|---|---|---|
| 点单页连续滚动 | 60 | 17ms | 0 |
| 连点 5 次加号（5 次落印 + 角标弹跳） | 58 | 33ms | 0 |
| 打开拆开看看（舞台升起 + 4 层错峰） | 60 | 17ms | 0 |
| 详情页连续滚动（大图视差 + 墨迹渐显） | 60 | 17ms | 0 |

**这个数据的边界要说清楚**：限速只模拟了「CPU 慢」，模拟不了「手机显卡弱」，而毛玻璃最吃的恰恰是显卡。所以这只证明页面脚本和动画在慢 CPU 上不卡；真正的低端安卓毛玻璃表现，要拿真机看（见第五节 #1）。lite 档会自动关掉毛玻璃兜底。

### ② Dock 两版同一状态截图

`对比-Dock两版-同一状态.png`：同样的 13 道招牌菜、同样的购物车（招牌跳跳蛙 + 湘味油泼牛肉，2 件 RM 96），差别只在底部。V1 底部只占一层，**一屏多露出半道菜**；V2 保留了旧版验证过的「黑底购物车条」结算锚点。

### ③ 淡黄 / 淡绿两套 token 分开交付

`tokens-淡黄.css`、`tokens-淡绿.css` 两个独立文件，变量名完全一致，换底色只换文件。最终留一版，另一版留档（换季、换主题零成本）。结构色备选（墨黑）在同一文件里用 `data-struct="ink"` 切换。

## 五、英文字体（41号 ④）

马善政的同一条管线：Cinzel 字体（SIL OFL 许可，许可证随字体放在 `brands/<店>/fonts/source/OFL-Cinzel.txt`）只留 A–Z、数字和常用标点，**122.5KB → 9.5KB**；从自己的服务器加载，不碰谷歌。

- 管理脚本：`scripts/font-chars.ts` 把书法字体和英文字体放在一起管理，`npm run build:font` 一次生成两个。
- 缺字拦截：英文标签里如果出现了字体里没有的字符（比如小写字母），数据校验直接报错。
- 英文标签（40号 §四终版）已进品牌配置 `brand.json` 的 `englishLabels`，小样里已去掉「待批」。
- 生产页面已经能加载这个字体（`@font-face` 已注入），但**还没有任何生产页面用到英文标签**，等全量铺开时才用。

## 六、我自己发现的问题（8 条）

1. **截图里深色 Dock 背后的部分文字没有被模糊**：反复排查后确认，是无界面浏览器软件渲染的问题——同一个页面里，价格、加号被模糊了，菜名和书法缩略图却没有；最简单的测试页面又能正常模糊。真机（手机显卡合成）大概率正常，但我这里没法验证。**兜底**：深色玻璃不透明度从 78% 提到 88%，就算模糊失效，背后内容也不会抢视线。建议老板在手机上实际看一次（见第七节）。
2. **帧率测试只模拟了慢 CPU**，没模拟弱显卡（见第二节①）。
3. **详情页印章出现了 6 次**（大图、4 个区块标题、风味之路），可能把「锚点」用成了「花边」。办法：A. 只留大图和风味之路两处（推荐）；B. 保持现在。
4. **缩略图首字重复**：招牌跳跳蛙 / 招牌剁椒鱼都是「招」，湘西土匪鸭 / 湘味油泼牛肉都是「湘」。比稿报告里提过「跳过招牌、特色这类前缀取下一个字」，还没拍板，小样里照首字显示。
5. **英文标签草表用的是 11号分区名**（如「水果柠檬茶」「招牌烧菜」「店长推荐」），顾客端现在的中文分类名是「小甜水」「精品肉菜」「招牌菜」（22号 #19 待高斯定）。英文按分类编号对应，不会配错，但中文名定下来后建议再对一眼英文。
6. **Cinzel 是 9.5KB 不是「几 KB」**：只保留了一个字重（600）。如果以后想要粗细不同的英文，保留可变字重是 16.5KB。
7. **墨晕比较淡**：程序化墨晕为了不抢菜单，透明度只有 26%，远看像「纸上的晕染」而不是「水墨山水」。如果老板要更明显的水墨意境，就走 40号 Q3 的军师生图管线出专项底图。
8. **V1 Dock 的页签只有图标没有字**：为了给「去结算」腾位置。年纪大的顾客可能认不出图标；选中项有浅色药丸，问题不大，但要老板判断。

另：第四批交付说明里写的许可证文件名 `OFL.txt` 已改成 `OFL-MaShanZheng.txt`（为了和 Cinzel 的许可证区分）。
