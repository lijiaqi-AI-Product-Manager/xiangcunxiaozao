5. **谷雨的底部导航是浮起来的白色胶囊**，选中项是浅黄绿实心图标；点单页是左侧分类栏 + 右侧大图卡，分组标题写「名茶冷萃 | CHINA TEA」。→ 浮动胶囊 Dock、分组标题中英混排的直接依据。
6. **绿茶的菜名前有一根金棕色的渐变「书签条」**，区块标题是一个字一个深绿方块竖着叠（品 / 牌 / 起 / 源），旁边是宽体大写衬线英文，再压一个小红印。→ 湘村详情页区块标题、菜名样式的直接依据。

## 一、全局设计系统（两页小样和后续五页共用）

### 1.1 底色：淡黄主底 + 淡绿饮品区（两版都做成 token，小样双版给高斯定）

| token | 淡黄版 | 淡绿版 | 说明 |
|---|---|---|---|
| 页面渐变 | `#FBF2DA → #FDF8EC → #FFFCF6`（上到下） | `#ECF4DD → #F5F9EC → #FCFDF8` | 永远不是纯色（铁律 2） |
| 主光源 | 右上角径向光 `rgba(255,206,130,.35)` | 右上角 `rgba(186,224,140,.35)` | 每屏一个光源感（§2.5-5） |
| 卡片 | 白 72% 透明 + 背景模糊 16px | 同左 | 毛玻璃浮在渐变上（铁律 8） |
| 卡片不支持模糊时 | 白 94% 不透明 | 同左 | 老机兜底 |

### 1.2 颜色

| 用途 | 色值 | 来源 |
|---|---|---|
| 主文字（暖墨） | `#2B2622` | 原 `#333` 偏冷，换暖墨与淡黄同族 |
| 次文字 | `#6E655B` | 对淡黄底对比度 ≥ 4.5（小样里自动校验） |
| 弱文字 | `#9E958A` | 只用于说明性小字 |
| 印章红（行动色） | `#C8372D` 实心 / 描边 / `rgba(200,55,45,.10)` 浅底 | 33号「一种红三浓度」 |
| 深墨绿（结构色） | `#1F3D2E` | 区块标题方块、英文标签（亚朵 8.6、绿茶 8.10）。备选 `#2B2622` 墨黑，小样两种都放 |

### 1.3 形状、阴影、字

| 项 | 规格 |
|---|---|

| 浅色阴影 | `0 4px 20px rgba(43,38,34,.04), 0 2px 8px rgba(43,38,34,.03)`（14.3，阴影带暖墨色不带纯黑） |
| 红色辉光 | 主按钮、加号：`0 6px 16px rgba(200,55,45,.28)`（玻尔 FAB 辉光，8.1） |
| 深色锚点发光 | Dock、会员卡：`0 0 0 1px rgba(255,255,255,.08) inset, 0 8px 24px rgba(31,61,46,.25)` |

### 1.4 两个全局组件

- **浮动胶囊 Dock**（Apple Music 8.7、谷雨）：离底 12px、左右 16px、圆角 24、深色毛玻璃 `rgba(30,26,22,.78)` + 模糊 24px，四个面性图标 + 字；选中项被浅色药丸包住。
- **墨晕层**（亚朵 8.6、40号 Q3）：小样用程序化墨晕——SVG 噪声滤镜画一次远山水墨，生成后缓存成一张图片，**不逐帧计算**；观感不够再走军师生图管线出一张专项底图。

## 二、五页方案

每页三层：① 基础改造 ② 光效动效 ③ 依据与工程。动效全部只用 transform / opacity；每项都写了「减弱动态效果」打开后的样子。

### 页 1　点单页（效率区）

**① 基础改造**

| 区域 | 方案 |
|---|---|
| 顶部门店区 | 墨晕远山层（高约 200px，向下渐隐）上浮一张毛玻璃门店卡：印章 + 店名（黑体 Heavy 20）+ 桌号胶囊 + 「当前等待约 16 分钟」；下面一行信任条「明厨亮灶 · 当日现采 · 一菜一锅」，点号换成小红印点。往下滑 40px 后门店区收成一行吸顶条，**保证一屏 ≥ 6 道** |
| 分类条 | 吸顶毛玻璃（模糊 20px）；选中项 = 浅色药丸 + 深墨字（小米 / Apple Music 的「容器填充」选中态），去掉现在的红下划线和 ▼ 黑三角；右侧「全部分类」改谷雨式「字 + 圆圈箭头」 |
| 分组标题 | 「店长推荐」黑体 Bold 18 + 「CHEF'S PICKS」英文小字 + 句尾小红印（谷雨「名茶冷萃 \| CHINA TEA」、绿茶印章结束符） |
| 菜卡 | 每组一张毛玻璃大卡（圆角 20），组内行与行之间细分隔线；缩略图 64 圆角 16 书法首字（墨色，推荐）；菜名 Bold 16、一句话 14 一行截断、价格 Bold 18 红；加号视觉 36px 实心红 + 红辉光，**点击热区 44px** |
| 主次 | 不靠放大卡片（会掉密度），靠「招牌标记」：店长推荐、镇店硬菜的行左侧加金棕书签条 + 「招牌」小印章角标（绿茶书签条），38号 13.2「效率区 + 画册区分区共存」——画册感放到详情页 |
| 购物车 / 导航 | **两个变体并排给高斯选**（40号 §三-4）：V1「并入 Dock」——购物车有东西时 Dock 左半显示件数和金额、右半变成红色「去结算」胶囊，四个页签缩成图标；V2「现状版」——深色毛玻璃购物车条浮在 Dock 上方 |

**② 光效动效**

| 效果 | 档位 | 规格 | 减弱动态后 |
|---|---|---|---|
| 背景光源低速漂移 | 推荐 | 右上角径向光 30 秒一个来回，只动 transform | 光源固定不动 |
| 分类氛围色 | 推荐 | 滑到饮品区，背景层在 2.4 秒内过渡到淡绿；只动背景层，不动卡片（40号条件） | 直接切换，不过渡 |
| 墨晕视差 | 推荐 | 墨晕层随滚动以 0.3 倍速度位移 | 墨晕层固定 |
| 加购落印（签名动效） | 推荐 | 点加号：印章字在加号位置盖下（放大 1.25 → 1、旋转 −8°，260ms），购物车角标放大回落，1.5 秒后静默（喜茶角标衰减 16.1） | 印章直接出现、不缩放；角标数字直接变 |
| 触摸涟漪光 | 推荐 | 点击处一圈淡红径向光晕，300ms 散开；**和落印不同时触发**（加号上只落印） | 关闭 |
| 按压缩放 | 必做 | 可点元素按下 0.96，120ms | 关闭（仍有颜色变化反馈） |
| 首次进入淡入 | 必做 | 只在第一次打开时，菜卡分组依次淡入 200ms；之后切页不再播 | 直接显示 |
| 毛笔进度 | 可选 | 等待分钟数旁一笔毛笔笔触随时间描出（40号：氛围不是进度条本体，分钟数仍是文字） | 笔触静态完整显示 |

**③ 依据与工程**：13.2 列表页公式、8.7 / 谷雨浮动 Dock、8.5 透明度选中态、16.1 角标衰减、铁律 10 效率底线。性能：页面上同时最多 3 层毛玻璃（门店卡、分类条、Dock）；lite 档改不透明底。

## 三、效果菜单汇总（按 40号 §三调整后）

| 档位 | 项目 |
|---|---|
| **必做**（底线） | 9 条判死项清零；十条铁律达标；性能三档自动判定 + 手动省电；按压缩放；首次淡入；拆开看看重做（去布局动画）；取餐页三重编码；完成提醒；卡片悬停；全部动效的减弱降级 |

## 六、工程方案（批准后才动）

- **token**：在品牌配置里新增顾客端「大改版」两套（淡黄 / 淡绿），骨架态（26号）不动；全部颜色仍只走 token，代码里 0 散写色值（现有检查脚本继续拦）。
- **动效**：统一一个动效模块管理三档和减弱动态，所有动画只用 transform / opacity；毛玻璃用 `@supports` 兜底。
- **自动验收**（每批都跑）：一屏 ≥ 6 道、触控 ≥ 44px、正文 ≥ 14px、文字对比度 ≥ 4.5、减弱动态下无任何动画、lite 档下无毛玻璃，全部写成端到端检查；继续沿用批 2 的逐道验收。
- **范围**：只改视觉层和交互层；菜单数据、账本、看板口径零改动（39号红线 1）。

## 八、我自己发现的风险（6 条）

1. **毛玻璃在低端安卓上很贵**：已在 lite 档改不透明底，并限制同屏最多 3 层；小样会用低配模拟测一次帧率。
2. **效果太多会变「烟花」**：每页只允许 1 个常驻环境效果 + 白名单微反馈；小样里如果哪页「吵」，先砍可选档。
3. **书法取餐号的辨认度**：马善政的数字笔画有飞白，店员喊号、顾客对号都要一眼认清。小样里书法号旁边配一行黑体小号数字兜底，老板看图决定要不要留。
4. **系统衬线英文各手机不一样**：iPhone 和安卓的默认衬线差别很大，绿茶那种宽体效果出不来；要一致就得自托管一款英文字体（另批）。
5. **毛玻璃上的文字对比度**：彩色光晕 + 半透明卡片叠在一起，次文字可能掉到 4.5 以下；小样自动检查每一处，不达标就加深卡片底。
6. **17 页亲选 PDF 还没到**：反例 7 页、正例 10 页里可能有和本方案冲突的细节；到了我会对照一遍，有冲突单独列出。
