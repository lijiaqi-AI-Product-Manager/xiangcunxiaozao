## 一、三模式怎么给湘村配比

军师预判「新中式为主 + 清新浅彩为辅 + 局部深色光感点缀」。**我同意大方向，但配比和落点有自己的判断**：

| 模式 | 占比 | 用在哪里 | 理由 |
|---|---|---|---|
| **C 新中式诗意**（主） | 约 60% | 全局底色（淡黄 / 淡绿纸感层）、水墨意境层、书法 + 印章、中英混排、竖排侧标、留白；详情页画册区最浓 | 38号第十篇场景映射直接写了「湘村小灶 C 端 = 新中式诗意」；老板口述「淡黄或淡绿，诗意和文艺」「水墨水染适合湘菜馆」 |
| **B 清新浅彩**（辅） | 约 30% | 功能区：莫兰迪浅卡做分区（会员、取餐信息、信任条）、面性马卡龙图标、**亮版 Gemini 色环用在取餐页状态**、弥散光晕 | 新中式只有意境没有效率；顾客点单是功能场景，需要同程那种「一眼找到功能」的浅彩语言撑住。38号 13.2 列表页公式本身就是清新渐变顶 + 紧凑列表 |
| **A 深色光感**（点缀） | 约 10%（顾客端）；老板端 100% | 顾客端只用在三处「锚点」：浮动购物车 / 导航 Dock（深色毛玻璃）、会员卡（深墨发光卡）、取餐号翻牌那一刻的聚光。老板端看板整页深色光感（38号 13.8 蚂蚁公式，39号上部已裁） | 顾客在白天的店里用手机点菜，整页深色会显得压抑、和「诗意」打架；但深色小面积放在底部和会员卡上，正好是视觉重心和情绪记忆点（旧版黑底购物车条就是这么用的，33号已吸收） |

**底色：淡黄还是淡绿？** 38号附录 A 写明「淡黄 / 淡绿最终拍板待 D1/D2 比稿」。我的倾向是**淡黄为主底**：湘菜的辣椒红、印章红、腊味棕都是暖色，在淡黄上是同族和谐；在淡绿上，红绿互补会「跳」（容易显得像圣诞配色），而且淡绿偏「清淡 / 健康」，和湘菜的烟火气相反。淡绿我建议留给饮品区（见第四节自主增值 1）。**两种底色在小样里都会做成 token，老板看图定。**

### 我自己额外查出的一条（不在 §9 里，但违反 39号红线 5）

**「拆开看看」展开动画用的是 `grid-template-rows` 过渡**，这属于布局属性动画，每一帧都触发重排，正是 39号红线 5「禁 layout 属性动画」要禁的。大改时改成只用 transform / opacity。

另外：上一轮比稿稿子里的加号是 32px，**低于 38号 16.4 和铁律 10 的 44px 触控底线**（线上生产版是 44px，没问题）。小样会保持视觉 32px、点击热区 44px。

## 四、十条铁律 → 湘村落地方案

| 铁律 | 湘村怎么落 |
|---|---|
| 1 界面必须有情绪（每页一个记忆点） | 点单页 = 水墨远山 + 毛玻璃门店卡；详情页 = 书法大标题光晕 + 竖排英文侧标；取餐页 = 状态色环 + 取餐号翻牌；我的页 = 深墨发光会员卡；看板 = 发光数据卡 |
| 2 背景不纯白不纯黑 | 顾客端底 = 淡黄纸感渐变（顶部略暖、底部略浅，带一处径向光源）；卡片白色但叠主题色 5% 透明底；老板端深底叠深蓝渐变（已有，加发光） |
| 3 圆角 16 起步，重点 20–24 | token 改为：小件 16、卡片 20、浮层与 Dock 24、按钮全胶囊；缩略图 16（38号 6.6 列表项 8px 是 B 模式写法，湘村按铁律 3 取 16） |
| 4 光取代影 | 浅色：多层柔和影 `0 4px 20px rgba(0,0,0,.03), 0 2px 8px rgba(0,0,0,.02)`（14.3）；主按钮和加号用红色辉光投影；深色锚点（Dock、会员卡）用内外发光不用黑影 |
| 5 图标面性 + 色彩 | TabBar 加面性图标（选中 = 药丸容器 + 实心，未选 = 描边）；「我的」页入口用圆形容器 + 马卡龙色；**图标我会用代码画（SVG），不出图** |
| 6 动效是氧气不是烟花（双层） | 常驻层：底色光斑低速漂移（20 秒以上一个周期）、取餐页色相缓慢推移；高频层：加购弹跳、拆开看看错峰 120ms、按压缩放、首次进页淡入 200ms。全部只动 transform / opacity；`prefers-reduced-motion` 一键全关 |
| 7 色彩即状态 | 取餐页三态色环（待制作 / 制作中 / 已完成）；老板端新单到达时看板顶部环境光脉冲一次；身份元素（取餐号、订单卡、用户的桌号）颜色恒定 |
| 8 透明度做层次 | 吸顶门店栏、分类条、浮动 Dock、购物车、底部弹层全部毛玻璃；**删掉所有用边框堆层次的写法**（现在的输入框、支付选项、加购栏都靠 1px 灰边框） |
| 9 中英混排 + 印章 + 留白 | 分组标题「招牌菜 SIGNATURE」式中英混排；印章做区块结束符；详情页留白加大。**注意：英文标签是新文案，不在任何批准稿里，需要先出一张中英对照表请老板 / 军师批，批之前小样里用占位标注**（见第五节问题 2） |

## 五、给军师的问题（审单时一并回答即可）

1. **判例原图能不能给我？**（见第〇节）
2. **英文标签谁来写？** 中英混排要给每个分类、区块配英文（如「招牌菜 SIGNATURE」「源流 ORIGIN」）。这是新文案，按纪律不能由我编。建议：我出一张中英对照草表（标「待批」），军师改、老板批，批完进品牌配置。
3. **水墨背景从哪来？** 水墨远山是图像。两条路：A. 走生图管线出一张（要放行，否则算抢跑出图）；B. 我用代码生成程序化的墨晕纹理（不算出图，但观感不如真水墨）。五页方案里两条都会给成本对比。
4. **淡黄 / 淡绿**：我倾向淡黄主底 + 淡绿只给饮品区（理由见第一节），小样两种都做。

## 六、预告：第二步五页方案里会展开的自主增值项（先列题目，审过再展开）

1. **分类氛围色**：滑到饮品区底色缓慢过渡到淡绿薄荷，湘菜区回到淡黄暖色（Gemini「色彩即状态」改成「色彩即分类」）。
2. **触摸涟漪光**：顾客 99% 用手机，鼠标拖尾用不上；改成点击处一圈 300ms 的淡红径向光晕（16.2 的手机版）。网页端拖尾放在老板端。
3. **加购「落印」**：加购时加号处盖一下印章（放大回落 + 微旋），代替通用弹跳，做成湘村独有的记忆点（第七篇印章资产）。
4. **购物车并入浮动 Dock**：现在购物车条和 TabBar 上下叠了两层，吃掉底部 120px；合进一个浮动胶囊，一屏还能多露半道菜。
5. **等待时长「毛笔进度」**：等候分钟数配一笔毛笔笔触进度（13.7 新中式加载语言），替代纯文字。
6. **性能三档自动判定 + 手动省电**：按设备内存、CPU 核数、系统「减弱动态效果」、省流量模式自动选 normal / minimal / lite，「我的」页再给一个手动开关。
7. **夜宵时段**（可选）：晚上 9 点后环境色转深墨夜色，招牌夜宵菜（跳跳蛙）微光强调；营业时间数据到位后才有意义。
