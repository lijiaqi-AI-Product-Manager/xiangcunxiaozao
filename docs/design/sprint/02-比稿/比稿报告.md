## 二、推荐顺序：A ＞ C ＞ B

### 第 1 名：A「紧凑效率」——推荐作为底子

一句话：把旧版做对的事（红色决策色、紧凑列表、详情页舞台按钮）收进新版的规矩里。

- **四个病灶全治**：一屏从 3 道到 6 道（病灶②）；红色覆盖所有「要顾客动手」的地方：价格、+ 号、选中分类下划线、主按钮、步骤序号、「拆开看看」（病灶③）；书法首字缩略图 + 信任条 + 印章让湘菜气质出来了（病灶④）。
- **详情页吸收了旧版最好的一招**：「拆开看看」做成实心红胶囊，压在大图底部正中，一眼就知道这道菜能拆开看。
- **改造成本最低**：结构就是现在的结构（顶部横滑分类 + 左图右文），主要改尺寸、颜色分配和详情页布局，不推翻组件。
- 短板：一句话要给加减按钮让位，长句会截成「…」；情感浓度不如 C。

### 第 2 名：C「纸本菜谱」——气质最强，有两处值得借给 A

- **左侧分类竖栏一次显示全部 12 个分类**，顾客不用横滑就知道有什么；A 的顶部横滑一屏只露 4 个。
- **详情页最像一本菜谱**：细双线画框、居中书法标题、菱形区块标记、虚线分隔、印章式「风味之路」，湘菜烟火气最足。
- 没排第一的原因：+ 号是描边红（三种浓度里的第二档），加购按钮的存在感比 A 弱，这对点单页是硬伤；去卡片化之后整体偏「文艺」，离老板定的喜茶克制高级感远一点；竖栏占掉 76 像素，菜名和一句话的空间更窄。

### 第 3 名：B「主次大卡」——最像喜茶，但现在不适合

- 招牌菜主推横滑大卡 + 下面普通列表，主次最明显；详情页大图 + 上滑面板最「高级」。
- 排最后的原因：**大卡要靠真实菜品图撑**，现在 102 道全是占位，大卡就是一块块米色方框写着菜名，主推感出不来；主推横滑把招牌菜藏在屏幕外，违反「F 型一眼扫」的点单习惯；为了守住一屏 6 道，普通列表被压得比 A 还紧，「呼吸感」名不副实。
- 等成品图上线后，B 的主推横滑可以作为 A 的升级选项再拿出来看。

### 推荐的混搭（要老板拍板，见第五节问题 2）

以 A 为底，借 C 两处：① 详情页的菱形区块标记和印章式「风味之路」标签；② 点单页要不要换成 C 的左侧竖栏（12 个分类全显示），我倾向**不换**，理由是竖栏让每道菜的文字区少 76 像素，而顶部横滑已经有「全部分类」按钮兜底。

## 五、需要老板拍板的问题（5 个）

1. **选哪个方向？** 推荐 A。
2. **混搭哪些？** 推荐「A + C 的详情页区块标记与印章式风味之路」；点单页是否改左侧竖栏，推荐不改。
3. **缩略图首字用什么颜色？** 推荐**墨色**。看 `对比-缩略图首字-墨vs红.png`：首字用红，每一行就有三个红（首字、价格、+ 号），红色不再代表「该点这里」；用墨色，红只留给价格和加购。
4. **首字重复怎么办？** 这是做稿时发现的：招牌跳跳蛙和招牌剁椒鱼都显示「招」，湘西土匪鸭和湘味油泼牛肉都显示「湘」，柠檬茶系列连着好几个「招」「单」。三个办法：A. 照首字，接受重复；B. **跳过「招牌」「特色」这类前缀取下一个字**（跳、剁、干），前缀清单放品牌配置，菜名本身一个字不改（推荐）；C. 每道菜人工指定一个字，104 道逐一定，工作量大。
5. **动效用哪一档？** 推荐 A 的「微反馈」：加购弹跳 + 拆开看看错峰两处；B 的首次淡入和呼吸可以等成品图上线后再加。

## 六、我自己发现的问题（6 条）

1. **详情页书法菜名出现两次**：占位图里写一遍全名，下面大标题再写一遍。这是占位阶段才有的重复，成品图上线后占位消失就好了；如果嫌现在重复，可以让详情页大图占位只写「成品图上线中」+ 印章，不写菜名（要改 26号大图占位规则，所以没改）。
2. **生产环境的购物车条下面有缝**：做 A 稿时发现，购物车条和底部页签之间有一条透明的缝，菜单内容会从缝里露出来（现在线上的点单页也是这样）。比稿里已经补了底色；实现时一起修。
3. **A、C 的一句话会被截断**：加减按钮占了右侧位置，像「现杀牛蛙，猛火快爆，肉嫩如蒜瓣」这种长句会截成「现杀牛蛙，猛火快爆，肉…」。点进详情页能看全，列表里截断是为了换一屏 6 道。
4. **第一版稿我自己没过关，改了一轮才交**：首字缩略图截到了兜底楷体（书法字按字懒加载，截图太早）；A、B 一屏只有 5 道（低于约定的 6）；分类条右边缘露出半个字；B 主推卡里加减按钮挤出卡片；C 竖栏把「一升霸王杯」折成「一升霸王 / 杯」；B 详情页的印章被面板盖住。以上都已修正后重截。
5. **喜茶小程序包仍然缺**：按 35号 Q1 用 23号的二手总结比稿，B 方向的「喜茶感」是按那份总结做的，像素细节没有原包对照。
6. **比稿只做了点单页和详情页**（33号范围）：VLM 病灶①说的是「我的」页、门店信息、常见问题像后台设置页，这三页不在比稿范围内。拍板后在实现方案里按选定方向一起改，届时单独出截图。
