# 打印机对接说明

> 顾客点单 → 小票机出整单明细、标签机出这单里的饮品杯贴（一杯一张）。已在本机用模拟打印机跑通全链路。

## 一、现在能做到什么

| 场景 | 表现 |
|---|---|
| 顾客下单 | 小票机出 1 张整单，标签机按饮品杯数出 N 张，**炒菜不出杯贴** |
| 打印机没开机 | 后台重试 3 次（1.5s / 3s 退避），失败写进 `print_jobs` 表，**顾客下单照常成功**（实测 51ms 返回） |
| 老板看状态 | 「打印设置」页两台机器各一行，通了显示「可连通」，不通翻成人话（「连不上：机器没开机，或者 IP 填错了」） |
| 纸没出来 | 「实时订单」每张单上有「补打小票 / 补打杯贴」，不用重下 |
| 装机当天 | 「打印设置」页点「打测试页」，机器立刻吐一张，确认纸宽、字号、切刀对不对 |

## 二、机器到店后你要填的 4 个参数

打开项目根目录的 `.env`，只改这几行：

```ini
# 小票机（芯烨 XP-236B）
PRINT_RECEIPT_ON=1
PRINT_RECEIPT_KIND=net          # 网口就写 net；USB 直插写 usb
PRINT_RECEIPT_HOST=192.168.1.100  # ← 打印机的 IP，见下面第 3 步
PRINT_RECEIPT_PORT=9100
PRINT_RECEIPT_PAPER=80          # 80 或 58

# 标签机（ZYWELL Zy307）
PRINT_LABEL_ON=1
PRINT_LABEL_KIND=net
PRINT_LABEL_HOST=192.168.1.101   # ← 第二台的 IP
PRINT_LABEL_PORT=9100
```

### 第 1 步：确认两台机器的接法

| 接法 | `KIND` 填 | 还要填 |
|---|---|---|
| 网线插路由器 / 打印机自带 Wi-Fi | `net` | `HOST` = IP，`PORT` 一般 9100 |
| USB 线直插跑程序这台电脑（Linux） | `usb` | `DEVICE=/dev/usb/lp0` |
| 已装系统打印驱动（Windows 共享） | `system` | `QUEUE=打印机名` |

**建议走网口**：USB 线一拔就断，且两台机器抢一个 USB 口容易打架。芯烨 XP-236B 有网口版本（型号带 N），Zy307 一般也带网口。

### 第 2 步：把打印机接入店里 Wi-Fi

芯烨和 ZYWELL 都支持「自检页打 IP」：关机 → 按住 FEED 键开机 → 松手，机器会吐一张自检页，上面有 `IP Address`。

更稳的做法是把两台机器在路由器里**固定 IP**（DHCP 静态绑定），否则路由器重启后 IP 一变，打印就断。

### 第 3 步：从跑程序的电脑验证通不通

```bash
# 换成你的打印机 IP
ping 192.168.1.100
nc -vz 192.168.1.100 9100     # 显示 succeeded 就通了
```

通了再去「打印设置」页点「打测试页」。**先过这一步再谈别的**——IP 不通，后面全是猜。

### 第 4 步：打测试页，看纸

| 看到什么 | 说明什么 | 怎么改 |
|---|---|---|
| 纸出不来，页面报「连不上」 | IP 错 / 机器没开 / 不在一张网 | 回第 3 步 |
| 出纸但全是乱码方块 | 编码不对 | `.env` 里 `PRINT_ENCODING=gb18030` 试试 |
| 出纸但右边被切掉 | 纸宽填大了 | `PRINT_RECEIPT_PAPER=58` |
| 出纸但字特别小/特别大 | 纸宽填反了 | 80mm 填 `80`，58mm 填 `58` |
| 出纸正常但没切 | 机器没有切刀 | `PRINT_RECEIPT_CUTTER=0` |
| 标签机走纸不准、贴不上杯 | 标签纸是模切的，切刀指令多余 | `PRINT_LABEL_CUTTER=0` |

## 三、两种纸长什么样

**小票（80mm / 48 列）**

```
              湘村小灶          ← 双高双宽
            取餐号 4            ← 三倍字号，出餐喊号用
             桌号 A07

------------------------------------------------
单号 004
时间 2026-10-25 21:56:03
------------------------------------------------
招牌跳跳蛙                              RM 48.00
  单价 48.00x1
干煸四季豆                              RM 18.00
  单价 18.00x1
招牌手打柠檬茶                          RM 39.80
  单价 19.90x2
西瓜椰青茶                              RM 11.90
  单价 11.90x1
------------------------------------------------
合计                                   RM 117.70
支付  现金（到柜台）
------------------------------------------------
备注：辣度：中辣；不要香菜
------------------------------------------------
          [CODE39 条码 1025-004]
```

**杯贴（一杯一张，只贴饮品）**

```
        桌 A07            ← 三倍字号
     招牌手打柠檬茶
       不要香菜           ← 规格印在名字正下方
      21:56  #004
         1/2
```

设计上有三个刻意的选择：

1. **炒菜不出杯贴**。饮品按 `brand.json` 的 `drinkCategories`（s/l/m/xl/can）判定。吧台一天几十单，炒菜也吐标签，废纸和撕标签的时间都是钱。
2. **单号是「月日-取餐号」**（`1025-004`），不是 UUID。顾客和店员都得念得出来、写得上。
3. **杯贴按 58mm（32 列）保守排**。标签纸宽度各家不一样，宁可窄一点居中，也不能折行溢出去——印出纸边的内容等于没印。

## 四、代码在哪

| 文件 | 干什么 |
|---|---|
| `apps/server/src/print/escpos.ts` | ESC/POS 指令拼装、全角半角宽度计算、折行 |
| `apps/server/src/print/templates.ts` | 小票与杯贴版式（纯函数，不碰网络） |
| `apps/server/src/print/transport.ts` | 四种接法：net / usb / system / mock |
| `apps/server/src/print/dispatcher.ts` | 串行队列、幂等、重试 —— 绝不阻塞下单 |
| `apps/server/src/print/log.ts` | 打印留痕落库（`print_jobs` 表） |
| `apps/server/src/print/index.ts` | 环境变量配置、订单 → 打印数据 |
| `apps/server/src/print/preview.ts` | 离线预览版式：`npx tsx apps/server/src/print/preview.ts` |
| `apps/admin/src/Printers.tsx` | 老板端「打印设置」页 |

不用真机就能调版式：

```bash
npx tsx apps/server/src/print/preview.ts
```

## 五、已知限制

- **菜品级备注还没有**。现在整单备注（「辣度：中辣；不要香菜」）会印到每张杯贴上——这是权宜之计。真正的「这杯少冰、那杯不加糖」需要给购物车加菜品级备注字段，改动面在购物车和下单接口，等确认要做再动。
- **钱箱**默认关着。小票机 RJ11 口接钱箱后，把 `PRINT_RECEIPT_DRAWER=1` 打开，打小票会顺带弹钱箱。
- **打印机状态是「连得上」不是「纸够不够」**。要看缺纸/开盖，得读打印机状态回传（DLE EOT），机型差异大，先不做。
