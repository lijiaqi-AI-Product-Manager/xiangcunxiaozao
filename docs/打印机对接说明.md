# 打印机对接说明

> 顾客点单 → **小票机**出整单明细、**标签机**出这单里的饮品杯贴（一杯一张，炒菜不出贴）。
> 本文按店里 2026-10 到货的两台机器写，照着做就能出纸；出问题时先查第六节的表。

## 一、先认清这两台机器

| | ZYWELL Zy307 | Xprinter 芯烨 XP-236B |
|---|---|---|
| 定位 | **80mm 热敏小票机** | **58mm 标签/杯贴机** |
| 打印宽度 | 80mm 纸，576 点 ≈ **48 列** | 48mm 打印区（58mm 纸）≈ **32 列** |
| 指令集 | ESC/POS | **双模**：票据 = ESC/POS，标签 = TSPL |
| 接口 | USB + **网口** | USB + 蓝牙（**没有网口**） |
| 切刀 | **有** | **没有** |
| 速度 | 230mm/s | 101mm/s |
| 其他 | 钱箱口 12V、缺纸/开盖检测 | 标签间隙传感器、蓝牙 |

两台都认 **ESC/POS**，所以代码只需要一套指令；差别只在**纸宽、有没有切刀、走什么线**——这三样在 `.env` 里各配各的（`PRINT_RECEIPT_*` / `PRINT_LABEL_*`）。

系统里两台机器的分工是这样定的：

- **Zy307 = 小票机**（有切刀、有网口、纸宽 80mm）：整单明细、取餐号大字、条码，给收银和顾客。
- **XP-236B = 标签机**（无切刀、纸窄）：每个饮品一杯一张，贴杯子上。

反过来也能用（XP-236B 当小票机、Zy307 当标签机），配置改一下就行，但**不建议**：58mm 打整单太挤，80mm 打杯贴浪费纸。

## 二、一条必须先说清的前提

**打印是从「跑后端的那台机器」发出去的，它必须和打印机在同一个局域网。**

```
后端进程 ──TCP 9100 / USB──> 打印机        ← 同一个路由器下面，才行
云服务器 ──公网──> 店里的打印机             ← 永远不通，它面前没有这台打印机
```

所以只有两种落地方式：

1. **后端就装在店里**（收银电脑 / 一台小主机 / NAS）。单店最省事，推荐。
2. 后端上云（Zeabur 等），店里再放一台机器跑**打印代理**——目前代码里没有这个东西，需要另做。

如果现在打算把后端放到云上，请先看完这一节再动手：云上跑起来的系统，下单、看报表都正常，**就是一拍单不出纸**，而且不是配置能解决的。

## 三、两台机器怎么接

| 机器 | 首选接法 | 次选 | 应急 |
|---|---|---|---|
| Zy307 | **网线插路由器**，`KIND=net`，`HOST=打印机IP`，`PORT=9100` | USB 插跑后端的电脑（Linux 才有 `/dev/usb/lp0`） | — |
| XP-236B | **USB 转网口打印服务器**（几十块钱，插上就是 `net`） | USB 插电脑 + 装驱动 + 开共享，`KIND=system` | 蓝牙配对一个 COM 口，`KIND=usb`、`DEVICE=\\.\COM5` |

为什么 XP-236B 首选打印服务器：它只有 USB 和蓝牙。USB 直插在 **Windows 上没有可写节点**（`\\.\USB001` 是假节点，写进去打印机不动），只能绕驱动；而打印机驱动有它自己的一套初始化，最容易出「Linux 上好好的、搬到 Windows 就打半张」。**一根网线/一个打印服务器，把这个问题从根上去掉。**

打印服务器的 IP 和打印机在两个网段也没关系，只要后端能 `ping` 到就行；端口填 9100（RAW）。少数便宜货只支持 LPR 515，那就得换个型号——这套代码只走 RAW。

## 四、`.env` 填什么

### 方案 A（推荐）：Zy307 打小票、XP-236B 打杯贴

```ini
# 小票机：ZYWELL Zy307，80mm，带切刀，网口
PRINT_RECEIPT_ON=1
PRINT_RECEIPT_KIND=net
PRINT_RECEIPT_HOST=192.168.1.100     # ← 打印机的固定 IP
PRINT_RECEIPT_PORT=9100
PRINT_RECEIPT_PAPER=80
PRINT_RECEIPT_CUTTER=1
PRINT_RECEIPT_DRAWER=0               # 接了钱箱再改 1
PRINT_RECEIPT_ENCODING=gbk

# 标签机：XP-236B，58mm 纸，无切刀（走 USB 转网口打印服务器）
PRINT_LABEL_ON=1
PRINT_LABEL_KIND=net
PRINT_LABEL_HOST=192.168.1.101
PRINT_LABEL_PORT=9100
PRINT_LABEL_PAPER=58
PRINT_LABEL_CUTTER=0                 # 没有切刀，填 1 会空吐一截纸
PRINT_LABEL_BIGTABLE=1               # 桌号用三倍字，远看得清；想省纸改 0
PRINT_LABEL_ENCODING=gbk
```

XP-236B 走 Windows 共享时，只改这三行：

```ini
PRINT_LABEL_KIND=system
PRINT_LABEL_QUEUE=XP236B             # ← 「打印机属性 → 共享」里填的共享名（别带空格）
PRINT_LABEL_HOST=
```

### 方案 B：XP-236B 当小票机

```ini
PRINT_RECEIPT_PAPER=58
PRINT_RECEIPT_CUTTER=0
PRINT_LABEL_PAPER=80
PRINT_LABEL_CUTTER=1
```

编码可以两台不一样（`PRINT_RECEIPT_ENCODING` / `PRINT_LABEL_ENCODING`），都没填就用 `PRINT_ENCODING` 兜底：

| 值 | 什么时候用 |
|---|---|
| `gbk` | 国产热敏机默认，芯烨/ZYWELL/佳博都吃这个 |
| `gb18030` | GBK 的超集，菜名里有生僻字（犇、麤）不丢字，字节长度不变 |
| `utf8` | 少数外贸机；**填错会整段乱码** |

## 五、装机六步

### 第 1 步：XP-236B 先确认在「票据模式」

XP-236B 是双模机，出厂可能停在**标签模式（TSPL）**。标签模式下收到 ESC/POS 指令，机器一声不响，什么也不打。

- 关机 → 按住 **FEED** → 开机 → 松手，打一张自检页；
- 看页头/页脚印的是 `TSPL` 还是 `ESC/POS`；
- 是 TSPL 就用芯烨的「打印机设置工具」（官网下载）切成「票据模式 / Receipt Mode」，或者按说明书做模式切换。

这一步没过，后面所有配置都是白配——现象就是「检测显示通了，打测试页不出纸」。

### 第 2 步：把两台机器接进店里路由器

- Zy307 网线插路由器；XP-236B 通过打印服务器插路由器。
- 打自检页（关机 → 按住 FEED → 开机），记下两台机器的 IP。
- **在路由器里做 DHCP 静态绑定**，把这两台钉死。不做的话路由器一重启 IP 就变，第二天早上不出纸。

### 第 3 步：从跑后端的电脑验通

```powershell
# Windows（PowerShell），把 IP 换成打印机实际的
Test-NetConnection 192.168.1.100 -Port 9100
```

```bash
# Linux / macOS
nc -vz 192.168.1.100 9100
```

`TcpTestSucceeded : True`（或 `succeeded`）才继续。**IP 不通的时候所有别的排查都是猜。**

### 第 4 步：填 `.env`，重启后端

改完 `.env` 要重启后端进程才生效（环境变量只在启动时读一次）。

### 第 5 步：老板端 →「打印设置」→ 打测试页

页面两行分别对应两台机器：

- 显示「网线通了（这只是基础检测，能不能出纸请点打测试页）」——正常，别当成成功；
- 显示「机器没回话 / 连不上 / 没找到」——照第六节的表改；
- 点「打测试页」，机器立刻吐一张示例单，含一行超长菜名（专门用来验折行）。

**先点测试页，再谈自动打印。** 测试页用的是和真单同一条链路，只是不占订单。

### 第 6 步：下一单真单

用顾客端下一单，检查四件事：

1. 小票出了 1 张，取餐号是大字，底下有条码；
2. 杯贴按饮品杯数出，一杯一张，炒菜没出贴；
3. 小票被切刀切断（Zy307）；
4. 后端重启后，这张单不会重打（幂等）。

## 六、出纸不对怎么查

| 看到什么 | 多半是 | 怎么改 |
|---|---|---|
| 测试页不出纸，但状态显示通 | XP-236B 还在 TSPL 标签模式 | 回第 1 步切成票据模式 |
| 打出来全是乱码/问号 | 编码不对 | 改 `PRINT_*_ENCODING=gb18030` 再试；还乱就换 `utf8` |
| 中文正常、偶尔几个字变问号 | 生僻字超出 GBK | `gb18030` |
| 右边被切掉半截 | 纸宽填大了 | 58mm 的机器填 `58` |
| 字特别小、一行挤很多 | 纸宽填小了 | 80mm 的机器填 `80` |
| 出纸后不切、拖着走 | 机器没切刀或 `CUTTER=1` 填反 | XP-236B 填 `0`；Zy307 填 `1` |
| 标签机空吐一段白纸 | 给无切刀机器发了切纸指令 | `PRINT_LABEL_CUTTER=0` |
| 标签纸上字压到缝里 | 标签纸是模切的，纸高和版式不匹配 | 用连续纸，或换成 40×30 的模切纸并把 `PRINT_LABEL_PAPER` 调好 |
| Windows 上 `KIND=system` 报「没开共享」 | 共享没勾或共享名不对 | 打印机属性 → 共享，勾上；共享名填进 `QUEUE` |
| 早上一来两台都不出纸 | IP 变了 | 路由器里做静态绑定 |
| 页面一直「未启用」 | `PRINT_*_ON` 还是 0，或改完没重启 | 改 1，重启后端 |

## 七、日常怎么用

- **补打**：老板端「实时订单」里每张单有「补打小票 / 补打杯贴」，不用重下单。
- **留痕**：每次打印（成功/失败/几张）都写进 `print_jobs` 表，打失败的单在「打印设置」页能看到，不会静默丢单。
- **换纸**：Zy307 用 80mm×φ80 热敏纸；XP-236B 用 58mm 热敏标签纸（或连续纸）。装纸时注意热敏面朝打印头。
- **清洗打印头**：出纸发白、有条纹时，用酒精棉签擦打印头（断电操作）。
- **打印机不参与下单**：打印机全关，顾客照样能下单，只是不出纸——这是故意的，纸不能挡住生意。

## 八、代码在哪

| 文件 | 干什么 |
|---|---|
| `apps/server/src/print/escpos.ts` | 指令拼装、汉字模式（FS &）、全角半角宽度、折行 |
| `apps/server/src/print/templates.ts` | 小票与杯贴版式（纯函数，不碰网络） |
| `apps/server/src/print/transport.ts` | 四种接法：`net` / `usb` / `system` / `mock` |
| `apps/server/src/print/dispatcher.ts` | 每台一条串行队列、幂等、指数退避重试——绝不阻塞下单 |
| `apps/server/src/print/log.ts` | 打印留痕落库（`print_jobs`） |
| `apps/server/src/print/index.ts` | 环境变量解析、订单 → 打印数据 |
| `apps/server/src/print/preview.ts` | 离线预览 + 逐行量宽度（超宽会直接标出来） |
| `apps/admin/src/Printers.tsx` | 老板端「打印设置」页 |

不接真机也能调版式：

```bash
npx tsx apps/server/src/print/preview.ts
```

会打印 80mm 小票、58mm 小票、58/80mm 杯贴四种版式，并逐行检查有没有超出纸宽。

## 九、已知限制

- **标签用 ESC/POS 打，不是 TSPL**。杯贴走票据模式，能打印纸、模切纸也行；但真正的标签排版（精确坐标、条码区、间隙校准）要用 TSPL，那是另一套指令，目前没做。
- **蓝牙只算应急**。配对的 COM 口波特率跟系统设置走，线一抖就断；长期用请上打印服务器。
- **钱箱**默认关。小票机 RJ11 接钱箱后 `PRINT_RECEIPT_DRAWER=1`，打小票会顺带弹钱箱。
- **状态检测只到「机器回没回话 / 缺纸 / 开盖」**（DLE EOT）。USB 和共享打印拿不到状态，只能验证「写得进去」。
- **后端上云就不用想 LAN 打印了**。要么后端在店里，要么以后加打印代理。
